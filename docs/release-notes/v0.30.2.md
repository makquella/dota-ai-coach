## Що нового

- **Таймер Рошана й Аегіса тепер отримує дані.** Грі бракувало одного рядка у файлі налаштування: Дота не надсилала події «Рошана вбито» й «Аегіс підібрано», тому підказки «Рошан може відродитися» й «Аегіс спливає» в справжній грі не з'являлися. Файл налаштування оновиться сам під час запуску Wardly — Доту доведеться перезапустити.
- **Предмети в рюкзаку більше не вважаються готовими.** Якщо Force Staff чи Healing Salve лежать у рюкзаку, тренер не радить їх натискати — звідти їх не використаєш.
- **Точніші підказки щодо прокачки.** Кнопки Dota Plus (дай п'ять, прапор гільдії) більше не сприймаються як вкладені очки навичок.
- **Перевірка даних гри у звіті про проблему.** Звіт тепер показує, які дані гра надсилає насправді (лише назви полів і лічильники — без ніків і Steam ID). Зіграйте один матч і надішліть звіт — так ми перевіримо, які підказки працюють у вас.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

- **The Roshan and Aegis timers now get their data:** the game config lacked one line, so Dota never sent the Roshan-killed and Aegis events and those hints never showed in a real game. The config updates itself when Wardly starts; restart Dota afterwards.
- **Items in the backpack no longer count as ready:** the coach does not tell you to press a Force Staff or a Healing Salve you cannot use from there.
- **Sharper skill-point tips:** the Dota Plus wheel (high five, guild banner) no longer counts as spent skill points.
- **The problem report shows what the game really sends** (field names and counts only, no nicknames or Steam IDs): play one match and send a report so we can check which hints work for you.
