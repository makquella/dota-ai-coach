## Что нового

- **Таймер Рошана и Аегиса теперь получает данные.** Игре не хватало одной строки в файле настройки: Дота не присылала события «Рошан убит» и «Аегис подобран», поэтому подсказки «Рошан может возродиться» и «Аегис истекает» в настоящей игре не появлялись. Файл настройки обновится сам при запуске Wardly — Доту нужно будет перезапустить.
- **Предметы в рюкзаке больше не считаются готовыми.** Если Force Staff или Healing Salve лежат в рюкзаке, тренер не советует их нажать — их оттуда не используешь.
- **Точнее подсказки о прокачке.** Кнопки Dota Plus (дай пять, знамя гильдии) больше не принимаются за вложенные очки навыков.
- **Проверка данных игры в отчёте о проблеме.** Отчёт теперь показывает, какие данные игра присылает на самом деле (только названия полей и счётчики — без ников и Steam ID). Сыграйте один матч и отправьте отчёт — так мы проверим, какие подсказки работают у вас.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **The Roshan and Aegis timers now get their data:** the game config lacked one line, so Dota never sent the Roshan-killed and Aegis events and those hints never showed in a real game. The config updates itself when Wardly starts; restart Dota afterwards.
- **Items in the backpack no longer count as ready:** the coach does not tell you to press a Force Staff or a Healing Salve you cannot use from there.
- **Sharper skill-point tips:** the Dota Plus wheel (high five, guild banner) no longer counts as spent skill points.
- **The problem report shows what the game really sends** (field names and counts only, no nicknames or Steam IDs): play one match and send a report so we can check which hints work for you.
