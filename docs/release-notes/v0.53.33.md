## Что нового

- **Прогресс применяет только актуальный ответ.** Старый запрос по другому герою или языку больше не заменяет текущий экран. Уход со вкладки отменяет применение ожидающего ответа и обновление AI-разбора; возврат к тому же герою начинает новое посещение. Быстрые переходы проверяются через настоящий IPC на русском и английском.

---

**In English:**
- **Progress applies only the current response.** An older request for another hero or language cannot replace the visible page. Leaving the tab invalidates pending responses and the AI review refresh; returning to the same hero starts a new visit. Actual IPC checks exercise rapid transitions in Russian and English.
