## Что нового

- **Прокачка в разборе матча.** Рядом со сборкой — карточка «Прокачка»: какое умение вы вкачали до конца первым и как максят умения про-игроки на этом герое (порядок целиком, ваше умение отмечено, сколько недавних про-матчей начинают так же).
- **Понятнее подписи.** «Ценность» в сравнениях теперь «Стоимость героя».

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

---

**In English:**
- **Skill order in the match review:** next to the build, a «Skill order» card shows which skill you maxed first and how pro players max their skills on this hero (the whole order, your skill marked, how many recent pro games start the same way).
- **Clearer labels:** the «LH at 10» column is now «Last hits by 10:00».
