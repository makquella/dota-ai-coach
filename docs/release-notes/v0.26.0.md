## Що нового

- **Прокачка в розборі матчу.** Поруч зі збіркою — картка «Прокачка»: яке вміння ви прокачали до кінця першим і як максять уміння про-гравці на цьому герої (порядок повністю, ваше вміння позначено, скільки нещодавніх про-матчів починають так само).
- **Зрозуміліші підписи.** «Цінність» у порівняннях тепер «Вартість героя».

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

**In English:**
- **Skill order in the match review:** next to the build, a «Skill order» card shows which skill you maxed first and how pro players max their skills on this hero (the whole order, your skill marked, how many recent pro games start the same way).
- **Clearer labels:** the «LH at 10» column is now «Last hits by 10:00».
