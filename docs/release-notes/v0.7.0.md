## Что нового

- **Поделиться прогрессом.** На «Прогрессе» появилась кнопка «Поделиться»: она создаёт ссылку на страницу с вашим прогрессом по всем героям — число матчей, победы и поражения, средние цифры, последние 10 матчей против 10 до них, главные герои, что получается и над чем работать, ваш фокус и, если отметите, вывод ИИ-тренера. В Discord и Telegram ссылка показывается с портретом вашего главного героя. Номера матчей, Steam ID, ник, другие игроки и ваши вопросы тренеру не публикуются. Ссылка работает 90 дней, её можно удалить в любой момент.
- **Заставка при запуске.** Пока запускается служба тренера, логотип оживает: кольцо дорисовывается, глаз открывается, красная точка бежит по кругу. Когда всё готово, открывается главное окно. При запуске вместе с Windows приложение по-прежнему стартует тихо в трее.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.
