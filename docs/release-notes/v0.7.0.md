## Що нового

- **Поділитися прогресом.** На «Прогресі» з'явилася кнопка «Поділитися»: вона створює посилання на сторінку з вашим прогресом по всіх героях — кількість матчів, перемоги й поразки, середні цифри, останні 10 матчів проти 10 до них, головні герої, що вдається й над чим працювати, ваш фокус і, якщо позначите, висновок ШІ-тренера. У Discord і Telegram посилання показується з портретом вашого головного героя. Номери матчів, Steam ID, нік, інші гравці й ваші запитання тренерові не публікуються. Посилання працює 90 днів, його можна видалити будь-коли.
- **Заставка під час запуску.** Поки запускається служба тренера, логотип оживає: кільце домальовується, око відкривається, червона крапка біжить по колу. Коли все готово, відкривається головне вікно. Під час запуску разом із Windows застосунок, як і раніше, стартує тихо в треї.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.
