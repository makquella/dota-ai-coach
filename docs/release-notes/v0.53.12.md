## Что нового

- **Быстрее проверки документации и сайта.** Windows-установщик собирается для изменений, которые могут затронуть приложение. Известные изменения вне desktop проходят остальные проверки без повторной сборки установщика.
- **Сохраняется обязательный результат проверки Windows.** Ошибка, отмена или необоснованный пропуск сборки не выдаются за успешную проверку.

---

**In English:**
- **Faster checks for documentation and site changes.** Windows installers are built for changes that can affect the app. Known changes outside desktop still run the other checks without rebuilding the installer.
- **A stable required Windows result.** A failure, cancellation or unjustified build skip cannot appear as successful validation.
