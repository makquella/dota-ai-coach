## Що нового

- **Швидші перевірки документації та сайту.** Windows-інсталятор збирається для змін, що можуть зачепити застосунок. Відомі зміни поза desktop проходять решту перевірок без повторного збирання інсталятора.
- **Зберігається обов'язковий результат перевірки Windows.** Помилка, скасування чи необґрунтований пропуск збірки не видаються за успішну перевірку.

---

**In English:**
- **Faster checks for documentation and site changes.** Windows installers are built for changes that can affect the app. Known changes outside desktop still run the other checks without rebuilding the installer.
- **A stable required Windows result.** A failure, cancellation or unjustified build skip cannot appear as successful validation.
