## Что нового

- **Автоматические обновления проходят проверку.** PR с данными игры и Python-зависимостями проверяются напрямую на своём SHA, включая Windows-сборку, даже если workflow token не запускает обычный CI. Есть сводка изменений и отдельные отчёты аудита зависимостей.
- **Единые версии инструментов.** Workflows используют Node 22 и Python 3.11 из общих файлов. Регулярные PR обновлений остаются доступными для проверки; автоматического merge нет.

---

**In English:**
- **Generated updates are validated.** Data/Python refresh PRs run CI directly on their immutable head, including Windows packaging, even when the workflow token cannot trigger ordinary PR CI. Change summaries and separate dependency audit reports are retained.
- **Tooling versions have one source.** Workflows use shared Node 22/Python 3.11 files. Scheduled dependency updates remain reviewable PRs without automatic merging.
