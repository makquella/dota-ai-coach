## Що нового

- **Автоматичні оновлення проходять перевірку.** PR з даними гри та Python-залежностями перевіряються безпосередньо на своєму SHA, зокрема Windows-збірка, навіть якщо workflow token не запускає звичайного CI. Є зведення змін і окремі звіти аудиту залежностей.
- **Єдині версії інструментів.** Workflows використовують Node 22 і Python 3.11 зі спільних файлів. Регулярні PR оновлень залишаються доступними для перевірки; автоматичного merge немає.

---

**In English:**
- **Generated updates are validated.** Data/Python refresh PRs run CI directly on their immutable head, including Windows packaging, even when the workflow token cannot trigger ordinary PR CI. Change summaries and separate dependency audit reports are retained.
- **Tooling versions have one source.** Workflows use shared Node 22/Python 3.11 files. Scheduled dependency updates remain reviewable PRs without automatic merging.
