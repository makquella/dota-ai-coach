## Що нового

- **Передбачуваніші збірки.** Бібліотеки тренера закріплено за версіями й перевіряються за хешами під час встановлення. Автоматичні перевірки й готовий застосунок використовують один набір runtime-залежностей.

---

**In English:**
- **More reproducible builds.** Coach libraries are pinned and verified by hash during installation. Automated checks and the packaged app use the same runtime dependency versions.
