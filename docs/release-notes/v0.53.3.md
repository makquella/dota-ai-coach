## Что нового

- **Более предсказуемые сборки.** Библиотеки тренера закреплены по версиям и проверяются по хешам при установке. Автоматические проверки и готовое приложение используют один набор runtime-зависимостей.

---

**In English:**
- **More reproducible builds.** Coach libraries are pinned and verified by hash during installation. Automated checks and the packaged app use the same runtime dependency versions.
