## Что нового

- **Прокачка без цикла импорта.** Названия и поля способностей нормализуются в чистом модуле, который используют GSI и skill build. Совместимые функции, нули, неизвестные значения и правила советов сохранены.
- **Строже проверка backend.** Удалено глобальное исключение F841; вызов, обновляющий игровой clock, сохранён без неиспользованного присваивания. Новые чистые модули проверяются strict mypy.

---

**In English:**
- **Skill building without an import cycle.** GSI and skill build use a pure ability normalizer. Compatible exports, zero, unknown values and advice rules are preserved.
- **Stricter backend checks.** The global F841 exception is removed; the game-clock update call remains without its unused assignment. The new pure modules are checked with strict mypy.
