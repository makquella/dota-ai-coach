## Що нового

- **Прокачка без циклу імпорту.** Назви й поля здібностей нормалізуються в чистому модулі, який використовують GSI та skill build. Сумісні функції, нулі, невідомі значення й правила порад збережено.
- **Суворіша перевірка backend.** Видалено глобальний виняток F841; виклик, що оновлює ігровий clock, збережено без невикористаного присвоєння. Нові чисті модулі перевіряються strict mypy.

---

**In English:**
- **Skill building without an import cycle.** GSI and skill build use a pure ability normalizer. Compatible exports, zero, unknown values and advice rules are preserved.
- **Stricter backend checks.** The global F841 exception is removed; the game-clock update call remains without its unused assignment. The new pure modules are checked with strict mypy.
