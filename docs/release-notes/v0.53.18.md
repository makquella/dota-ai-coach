## Що нового

- **Узгоджене зведення пам'яті матчу.** Читання зведення, надходження ігрових і демоданих та скидання сесії використовують спільний порядок доступу. Читач більше не отримує частково оновлену пам'ять посеред зміни героя чи запису стану.

---

**In English:**
- **Consistent match-memory summaries.** Reading a summary, observing game/demo data and resetting the session share an access order. Readers no longer receive partially updated memory during a hero change or state observation.
