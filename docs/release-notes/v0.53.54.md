## Что нового

- **Ключ устройства.** Вместе с отчётом, ссылкой «Поделиться», карточкой профиля и переносом истории приложение передаёт случайный ключ, который хранится зашифрованным на вашем компьютере. Сервер хранит только его хеш, и «Удалить мои данные на сервере» удаляет отправленное с ключом только при этом ключе — знать номер установки уже недостаточно.
- **Перенос по коду нельзя сорвать.** Отменить перенос (после получения истории его удаляет принимающий компьютер) теперь может только тот, у кого есть весь код, а не только первые четыре символа.
- **Старые данные не потеряны.** Всё, что отправили прежние версии, удаляется как раньше; карточка профиля получает ключ при следующей публикации.

---

**In English:**
- **Device key:** reports, shared reviews, the profile card and history transfers now carry a random key kept encrypted on your computer. The server stores only its hash, and «Delete my data on the server» removes what was sent with it only with that key; knowing the installation id is no longer enough.
- **A transfer cannot be cancelled by others:** cancelling a transfer (the receiving computer deletes it after import) now needs the whole code, not just its first four characters.
- **Older data keeps working:** whatever earlier versions sent is deleted as before; the profile card gets its key on the next publish.
