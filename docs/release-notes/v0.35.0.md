## Что нового

- **Друзья.** На вкладке «Профиль» появился раздел «Друзья». Нажмите «Показать профиль друзьям» — у вас появится код друга вида `WD-4K7P9QX2`. Отправьте его друзьям, а их коды добавьте к себе: в списке будет общий рейтинг — уровень, медаль, рейтинг, матчи за неделю и всё надетое оформление: рамки, цвет ника, титулы.
- **Профиль страницей.** Кнопка «Скопировать ссылку» даёт страницу `api.luhovyimvp.dev/p/<код>` с вашей карточкой — можно скинуть в чат или в Discord.
- **Под вашим контролем.** На сервер уходит только карточка: ник, титул, уровень, медаль, рейтинг (его можно скрыть), оформление, ступени наград и число матчей с Wardly. Без Steam ID и списка матчей. «Скрыть профиль» удаляет карточку с сервера, а список друзей хранится только на вашем компьютере.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **Friends:** the «Profile» tab has a «Friends» section. Press «Show my profile to friends» and you get a friend code like `WD-4K7P9QX2`; send it to friends and add theirs — the list ranks you all by level, medal, rating and matches this week, with everyone's looks: frames, name colours, titles.
- **Your profile as a page:** «Copy link» gives `api.luhovyimvp.dev/p/<code>` with your card, ready for a chat or Discord.
- **In your hands:** only the card goes to the server — name, title, level, medal, the rating (you can hide it), the looks, achievement tiers and the number of matches with Wardly; no Steam ID and no match list. «Hide my profile» deletes the card from the server, and the friend list stays on your computer.
