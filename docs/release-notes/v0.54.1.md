## Що нового

- **Голос без українського пакета.** Якщо в Windows немає українського голосу, поради тепер читаються англійською, а не мовчки. У «Налаштування → Голос» з'явилася підказка й кнопка «Додати голос», що відкриває параметри мовлення Windows; там можна додати український голос (Microsoft Ostap).
- **Природніша українська.** Виправлено кальки й неточності в підказках у грі («Таймінг за фармом: пришвидшіть фарм», «змістіться», «живучість»), у розборах («шкода героям», «орієнтир — …») і в налаштуваннях («Як зазвичай», «Від'єднати», «Чекаємо на гру»).

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

**In English:**
- **Voice without the Ukrainian pack.** When Windows has no Ukrainian voice, advice is now read in English instead of staying silent. Settings → Voice explains it and offers «Add a voice», which opens the Windows speech settings to add the Ukrainian voice (Microsoft Ostap).
- **More natural Ukrainian.** Calques and awkward wording fixed in the in-game tips, the reviews and the settings.
