## Что нового

- **Надёжнее восстановление истории.** Файл проверяется целиком до записи. Матчи, настройки, разборы и привязка аккаунта сохраняются одной операцией; при ошибке данные из файла не сохраняются частично. Существующие заметки и значения сохраняются.
- **Повреждённый кеш не мешает открыть разбор.** Тренер отмечает ошибку в отчёте о проблеме и продолжает работать; данные кеша можно получить заново обычным путём.

---

**In English:**
- **More reliable history restore.** The entire file is checked before saving. Matches, settings, reviews and account linking are restored in one operation; a failure leaves no partial restore. Existing notes and values are preserved.
- **A damaged cache no longer interrupts opening a review.** The coach records the error in the problem report and keeps working; cached data can be obtained again through the usual requests.
