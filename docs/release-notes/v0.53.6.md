## Що нового

- **Надійніше відновлення історії.** Файл перевіряється повністю до запису. Матчі, налаштування, розбори й прив'язка акаунта зберігаються однією операцією; у разі помилки дані з файлу не зберігаються частково. Наявні нотатки й значення зберігаються.
- **Пошкоджений кеш не заважає відкрити розбір.** Тренер позначає помилку у звіті про проблему й працює далі; дані кешу можна отримати знову звичайним шляхом.

---

**In English:**
- **More reliable history restore.** The entire file is checked before saving. Matches, settings, reviews and account linking are restored in one operation; a failure leaves no partial restore. Existing notes and values are preserved.
- **A damaged cache no longer interrupts opening a review.** The coach records the error in the problem report and keeps working; cached data can be obtained again through the usual requests.
