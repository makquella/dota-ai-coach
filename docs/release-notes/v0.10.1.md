## Исправлено

- **Запись матча не теряет секунды на необычных данных от Доты.** Если Дота присылала имя предмета или ник не текстом, этот момент матча пропадал из записи, а по такому первому пакету Steam-аккаунт мог не привязаться. Теперь такие поля просто пропускаются.
- **«Поделиться разбором»** больше не отвечает внутренней ошибкой на слишком длинный номер матча.
- Проверка приложения искажёнными данными GSI теперь ловит и ошибки записи матча, а не только ответы с ошибкой.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

---

**In English:** match recording no longer loses a tick when Dota sends an item name or nickname that is not text (and the Steam account still links from such a first payload); the share route answers a too-long match id with 422 instead of a server error; the GSI fuzzer now fails on match-recording errors too.
