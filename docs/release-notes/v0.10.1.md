## Виправлено

- **Запис матчу не втрачає секунди на незвичайних даних від Доти.** Якщо Дота надсилала назву предмета чи нік не текстом, цей момент матчу зникав із запису, а за таким першим пакетом Steam-акаунт міг не прив'язатися. Тепер такі поля просто пропускаються.
- **«Поділитися розбором»** більше не відповідає внутрішньою помилкою на надто довгий номер матчу.
- Перевірка застосунку спотвореними даними GSI тепер ловить і помилки запису матчу, а не лише відповіді з помилкою.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

---

**In English:** match recording no longer loses a tick when Dota sends an item name or nickname that is not text (and the Steam account still links from such a first payload); the share route answers a too-long match id with 422 instead of a server error; the GSI fuzzer now fails on match-recording errors too.
