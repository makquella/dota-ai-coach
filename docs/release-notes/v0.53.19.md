## Що нового

- **Скидання сесії не чекає на читання історії для визначення ролі.** Дані про роль готуються перед оновленням ігрового стану. Попередні правила для кора й саппорта зберігаються, а помилка читання цих даних не залишає частково оновленої пам'яті матчу.

---

**In English:**
- **Session reset no longer waits for role-history lookup.** Role metadata is prepared before updating game state. Existing core/support rules are preserved, and a metadata read failure does not leave partially updated match memory.
