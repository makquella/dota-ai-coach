## Что нового

- **Сброс сессии не ждёт чтения истории для определения роли.** Данные о роли готовятся перед обновлением игрового состояния. Прежние правила для кора и саппорта сохраняются, а ошибка чтения этих данных не оставляет частично обновлённую память матча.

---

**In English:**
- **Session reset no longer waits for role-history lookup.** Role metadata is prepared before updating game state. Existing core/support rules are preserved, and a metadata read failure does not leave partially updated match memory.
