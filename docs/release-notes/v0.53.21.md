## Что нового

- **Согласованное чтение live-трекеров.** Сведения о видимых врагах, линии, TP и событиях Рошана/Аегиса собираются одним снимком памяти матча. Обновление игры и сброс сессии больше не могут вклиниться между этими чтениями; возвращённые данные отделены от трекеров.

---

**In English:**
- **Consistent live tracker reads.** Observed enemies, lane signals, TP and Roshan/Aegis events are captured in one match-memory snapshot. Game updates and session reset cannot interleave between these reads; returned data is detached from the trackers.
