## Що нового

- **Узгоджене читання live-трекерів.** Відомості про видимих ворогів, лінію, TP і події Рошана/Аегіса збираються одним знімком пам'яті матчу. Оновлення гри й скидання сесії більше не можуть вклинитися між цими читаннями; повернені дані відокремлено від трекерів.

---

**In English:**
- **Consistent live tracker reads.** Observed enemies, lane signals, TP and Roshan/Aegis events are captured in one match-memory snapshot. Game updates and session reset cannot interleave between these reads; returned data is detached from the trackers.
