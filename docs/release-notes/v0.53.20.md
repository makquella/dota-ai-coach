## Что нового

- **Настройки таймеров загружаются до обновления состояния.** Первое событие Рошана или Аегиса больше не вызывает чтение файла внутри блокировок игрового состояния. Сброс продолжает отвечать, пока настройки готовятся для GSI; демо и прямое наблюдение используют тот же cache.

---

**In English:**
- **Timer settings load before state updates.** The first Roshan or Aegis event no longer reads a file inside game-state locks. Reset remains responsive during GSI timer preparation; demo and direct observation use the same cache.
