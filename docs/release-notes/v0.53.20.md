## Що нового

- **Налаштування таймерів завантажуються до оновлення стану.** Перша подія Рошана чи Аегіса більше не спричиняє читання файлу всередині блокувань ігрового стану. Скидання й далі відповідає, поки налаштування готуються для GSI; демо та пряме спостереження використовують той самий cache.

---

**In English:**
- **Timer settings load before state updates.** The first Roshan or Aegis event no longer reads a file inside game-state locks. Reset remains responsive during GSI timer preparation; demo and direct observation use the same cache.
