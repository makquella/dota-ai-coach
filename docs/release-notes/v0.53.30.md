## Що нового

- **Історія матчів зберігає останню вибірку.** Запізніла відповідь старого фільтра, сортування чи попереднього відвідування вкладки більше не замінює поточної таблиці. Повторні натискання «Ще» не додають одну сторінку двічі; зміна вибірки відхиляє стару сторінку. Перевірки проходять через справжній IPC обома мовами.

---

**In English:**
- **Match history keeps the latest selection.** A delayed response for an older filter, sort or tab visit cannot replace the current table. Repeated More clicks cannot duplicate a page, and changing selection rejects an older page. Actual IPC checks cover Russian and English.
