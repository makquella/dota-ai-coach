## Что нового

- **Проверено на настоящей игре.** По отчётам игроков подтвердилось: игра присылает тренеру врагов на мини-карте (все пять, без союзников), готовность предметов и их заряды, оглушения и события Рошана — значит, советы по предметам против врагов и таймер Рошана работают в реальном матче.
- **Таймер Рошана надёжнее.** События «Рошан убит» больше не теряются среди сообщений чата и других событий игры.
- **Отчёт о проблеме точнее.** Проверка данных игры не путает пустой инвентарь с отсутствием данных и показывает врагов только текущего матча.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **Checked on a real game:** player reports confirm the game sends the coach the enemies on the minimap (all five, no allies), item readiness and charges, stuns and the Roshan events, so the counter-item advice and the Roshan timer work in a real match.
- **A sturdier Roshan timer:** the Roshan-killed event is no longer lost among chat messages and other game events.
- **A more accurate problem report:** the game-data check no longer mistakes an empty inventory for missing data and lists only the current match's enemies.
