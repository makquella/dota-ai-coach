## Що нового

- **Запізнілі відповіді розбору перевіряють актуальність екрана.** Оновити розбір може лише останній запит для поточного матчу й мови. Вихід із вкладки скасовує застосування старої відповіді, зокрема й повернення до того самого матчу. Ці переходи перевіряються через справжні IPC-запити обома мовами.

---

**In English:**
- **Delayed review responses check the current view.** Only the latest request for the selected match and language can update the review. Leaving the tab invalidates older responses, including returning to the same match. Actual IPC checks exercise these transitions in Russian and English.
