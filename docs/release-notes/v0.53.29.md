## Что нового

- **Запоздавшие ответы разбора проверяют актуальность экрана.** Обновить разбор может только последний запрос для текущего матча и языка. Уход со вкладки отменяет применение старого ответа, включая возврат к тому же матчу. Эти переходы проверяются через настоящие IPC-запросы на русском и английском.

---

**In English:**
- **Delayed review responses check the current view.** Only the latest request for the selected match and language can update the review. Leaving the tab invalidates older responses, including returning to the same match. Actual IPC checks exercise these transitions in Russian and English.
