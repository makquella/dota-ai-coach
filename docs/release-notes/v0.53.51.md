## Что нового

- **Состояние операций.** В разделе «Для разработчиков» новый блок показывает задачи истории и ИИ-тренера (сколько ждут и как долго выполняется текущая), сохранение сыгранного матча (ждёт ли он записи, когда сохранён последний), задержки пути живого GSI (p50/p95) и свежесть данных (обновление матчей, дата встроенных сборок). Он обновляется сам, пока раздел открыт.
- **Понятные предупреждения.** Если задача застряла, матч не удалось записать, GSI тормозит или сборки устарели, блок пишет это одной строкой. Те же сведения (только числа и время, без номеров матчей и аккаунтов) попадают в отчёт о проблеме.
- **Проверка CI стабильнее.** Проверка workflow-файлов больше не скачивает Docker-образ, упиравшийся в лимит Docker Hub, а берёт ту же версию actionlint с проверкой контрольной суммы.

---

**In English:**
- **Operations health:** a new block in For developers shows history and AI coach jobs (how many wait and how long the current one runs), saving of the finished match (whether it waits for the store, when the last one was saved), live GSI timings (p50/p95) and data freshness (match sync, bundled builds date). It refreshes itself while the section is open.
- **Plain warnings:** a stuck job, a match the store refused, slow GSI or stale builds are named in one line each. The same facts (counts and times only, no match or account ids) go into the problem report.
- **Steadier CI:** workflow linting no longer pulls a Docker image that hit Docker Hub's rate limit; it uses the same actionlint release with a checksum check.
