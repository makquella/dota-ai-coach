## Що нового

- **Стан операцій.** У розділі «Для розробників» новий блок показує завдання історії та ШІ-тренера (скільки чекають і як довго виконується поточне), збереження зіграного матчу (чи чекає він на запис, коли збережено останній), затримки шляху живого GSI (p50/p95) і свіжість даних (оновлення матчів, дата вбудованих збірок). Він оновлюється сам, поки розділ відкрито.
- **Зрозумілі попередження.** Якщо завдання застрягло, матч не вдалося записати, GSI гальмує або збірки застаріли, блок пише це одним рядком. Ті самі відомості (лише числа й час, без номерів матчів і акаунтів) потрапляють у звіт про проблему.
- **Перевірка CI стабільніша.** Перевірка workflow-файлів більше не завантажує Docker-образ, що впирався в ліміт Docker Hub, а бере ту саму версію actionlint із перевіркою контрольної суми.

---

**In English:**
- **Operations health:** a new block in For developers shows history and AI coach jobs (how many wait and how long the current one runs), saving of the finished match (whether it waits for the store, when the last one was saved), live GSI timings (p50/p95) and data freshness (match sync, bundled builds date). It refreshes itself while the section is open.
- **Plain warnings:** a stuck job, a match the store refused, slow GSI or stale builds are named in one line each. The same facts (counts and times only, no match or account ids) go into the problem report.
- **Steadier CI:** workflow linting no longer pulls a Docker image that hit Docker Hub's rate limit; it uses the same actionlint release with a checksum check.
