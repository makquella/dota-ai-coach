## Що нового

- **Переносні перевірки розробки.** `scripts/dev.py` враховує staged, unstaged та untracked файли, вибирає перевірки споживачів і показує точні команди та робочі каталоги. Shared і невідомі межі розширюють перевірки.
- **Єдина версія випуску.** Окрема перевірка й CI звіряють обидві версії backend, launcher package/lock, каталог обома мовами та release notes. Optional hooks перевіряють один файл і дають підказку; типово їх вимкнено.

---

**In English:**
- **Portable development checks.** `scripts/dev.py` covers staged, unstaged and untracked files, selects consumer checks and shows exact commands/cwd. Shared and unknown boundaries expand validation.
- **One release version.** A dedicated gate and CI compare both backend values, launcher package/lock, RU/EN catalogs and release notes. Optional hooks check one file and offer a hint; they remain disabled by default.
