## Что нового

- **Переносимые проверки разработки.** `scripts/dev.py` учитывает staged, unstaged и untracked файлы, выбирает проверки потребителей и показывает точные команды и рабочие каталоги. Shared и неизвестные границы расширяют проверки.
- **Единая версия выпуска.** Отдельная проверка и CI сверяют обе версии backend, launcher package/lock, RU/EN каталог и release notes. Optional hooks проверяют один файл и дают подсказку; по умолчанию они выключены.

---

**In English:**
- **Portable development checks.** `scripts/dev.py` covers staged, unstaged and untracked files, selects consumer checks and shows exact commands/cwd. Shared and unknown boundaries expand validation.
- **One release version.** A dedicated gate and CI compare both backend values, launcher package/lock, RU/EN catalogs and release notes. Optional hooks check one file and offer a hint; they remain disabled by default.
