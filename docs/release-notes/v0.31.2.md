## Что нового

- **Отчёт о проблеме помнит прошлый матч.** Сводка о том, какие данные игра присылала тренеру, теперь сохраняется на диск. Если отправить отчёт после перезапуска приложения, в нём будет последний сыгранный матч, а не пустота.
- **Видно, почему приложение закрылось.** В журнал пишется причина выхода (кнопка «Выход» в трее, выход из Windows) и шёл ли в этот момент матч: так проще понять, почему матч остался без советов.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

---

**In English:**
- **The problem report remembers the last match:** the summary of what data the game sent to the coach is now saved to disk, so a report sent after restarting the app shows the last match played instead of nothing.
- **Why the app closed:** the log now says why it quit (the tray's Quit, Windows sign-out) and whether a match was going on at that moment, which explains a match left without advice.
