## Що нового

- **Звіт про проблему пам'ятає минулий матч.** Зведення про те, які дані гра надсилала тренерові, тепер зберігається на диск. Якщо надіслати звіт після перезапуску застосунку, у ньому буде останній зіграний матч, а не порожнеча.
- **Видно, чому застосунок закрився.** У журнал пишеться причина виходу (кнопка «Вихід» у треї, вихід із Windows) і чи йшов у цей момент матч: так легше зрозуміти, чому матч лишився без порад.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

**In English:**
- **The problem report remembers the last match:** the summary of what data the game sent to the coach is now saved to disk, so a report sent after restarting the app shows the last match played instead of nothing.
- **Why the app closed:** the log now says why it quit (the tray's Quit, Windows sign-out) and whether a match was going on at that moment, which explains a match left without advice.
