## Що нового

- **Менше однакових підказок мідерові.** Таймер руни сили тепер показується до 20-ї хвилини, а не кожні дві хвилини всю гру. До 6-го рівня з Bottle підказка радить покласти руну в нього й приберегти для вбивства після наступної хвилі.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.
