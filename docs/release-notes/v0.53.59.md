## Что нового

- **Быстрее при большой истории.** Таблица матчей, фильтр по герою и «Прогресс» больше не сортируют всю историю при каждом открытии: для их порядка появились индексы базы. На 3000 матчей дальние страницы таблицы открываются примерно втрое быстрее, а чтение данных для них — в 5–20 раз.
- **«Профиль» легче.** Профиль читает из всей истории только поля, нужные для рейтинга и достижений, без списков предметов и заметок — почти вдвое быстрее на большой истории.
- **Проверка на будущее.** Тест следит, чтобы списки матчей всегда шли по индексу, а скрипт замера показывает время чтений на любой синтетической истории.

---

**In English:**
- **Faster with a long history:** the match table, the hero filter and Progress no longer sort the whole history each time: the database has indexes for their order. With 3000 matches far pages of the table open about three times faster, and reading their data 5–20 times faster.
- **A lighter Profile:** the Profile reads only the fields its rating and achievements need from the whole history, without item lists and notes — almost twice as fast with a long history.
- **Guarded:** a test keeps the match lists on an index, and a benchmark script shows read times on any synthetic history.
