## Что нового

- **Проверка исправлений на записи.** Новый скрипт `replay_check.py` прогоняет четыре очищенных матча по ролям (керри, мид, оффлейн, саппорт) через весь путь живых советов с фиксированными часами и сравнивает, какие советы и подсказки карты показаны и когда, с принятым результатом. Расхождение выводится коротким списком «пропало / появилось» с командой для воспроизведения.
- **Тест на каждое изменение советов.** Эти прогоны входят в набор тестов, поэтому случайное изменение поведения тренера в игре видно сразу; намеренное — обновляет эталоны в том же изменении.

---

**In English:**
- **Checking a fix on recordings:** the new `replay_check.py` replays four sanitized role matches (carry, mid, offlane, support) through the whole live advice path with a fixed clock and compares which advice and map hints appear, and when, with the accepted results. A difference is printed as a short removed/added list with a command to reproduce it.
- **A test for every advice change:** these runs are part of the test suite, so an accidental change of the in-game coach shows up at once; a deliberate one updates the accepted results in the same change.
