## Що нового

- **Посилено автоматичні перевірки змін.** Нові помилки типів тепер зупиняють перевірку. Відомі старі помилки враховано окремо; після виправлення вони більше не отримують дозволу з'явитися знову.
- **Перевірки відтворювані.** Використовуються закріплена версія інструмента й одна конфігурація; зміни номерів рядків не приховують нових помилок і не створюють зайвого шуму.

---

**In English:**
- **Stronger automated checks for changes.** New type errors now fail validation. Existing debt is tracked separately; once fixed, an error is no longer allowed to return.
- **Reproducible checks.** A pinned tool and shared configuration keep line-number changes from hiding new errors or creating unnecessary noise.
