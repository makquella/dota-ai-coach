## Что нового

- **Усилены автоматические проверки изменений.** Новые ошибки типов теперь останавливают проверку. Известные старые ошибки учтены отдельно; после исправления они больше не получают разрешение появиться снова.
- **Проверки воспроизводимы.** Используются закреплённая версия инструмента и одна конфигурация; изменения номеров строк не скрывают новые ошибки и не создают лишний шум.

---

**In English:**
- **Stronger automated checks for changes.** New type errors now fail validation. Existing debt is tracked separately; once fixed, an error is no longer allowed to return.
- **Reproducible checks.** A pinned tool and shared configuration keep line-number changes from hiding new errors or creating unnecessary noise.
