## Что нового

- **Проверки перед выпуском установщика.** Версия исходного кода для сборки должна пройти общие проверки backend и интерфейса перед публикацией. Сборка использует тот же commit, даже если основная ветка уже обновилась.
- **Защита от несовпадения версии.** Выпуск останавливается, если исходники изменились после выбора commit или тег уже указывает на другую версию кода.

---

**In English:**
- **Validation before releasing the installer.** The source selected for a build must pass shared backend and interface checks before publication. The build uses the same commit even if the main branch has advanced.
- **Protection against source mismatches.** Release stops if tracked source changes after selection or the tag points to a different commit.
