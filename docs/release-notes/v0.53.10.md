## Що нового

- **Перевірки перед випуском інсталятора.** Версія вихідного коду для збірки має пройти спільні перевірки backend та інтерфейсу перед публікацією. Збірка використовує той самий commit, навіть якщо основна гілка вже оновилася.
- **Захист від розбіжності версії.** Випуск зупиняється, якщо вихідний код змінився після вибору commit або тег уже вказує на іншу версію коду.

---

**In English:**
- **Validation before releasing the installer.** The source selected for a build must pass shared backend and interface checks before publication. The build uses the same commit even if the main branch has advanced.
- **Protection against source mismatches.** Release stops if tracked source changes after selection or the tag points to a different commit.
