## Що нового

- **Анонімна статистика — лише якщо ви її ввімкнете.** У «Налаштуваннях → Застосунок» з'явився перемикач «Анонімна статистика», типово він вимкнений. Якщо ввімкнути, раз на день застосунок надсилає лічильники за минулий день:
  - скільки разів тренер показав підказку кожного типу;
  - після скількох термінових попереджень протягом 30 секунд була смерть;
  - скільки матчів розібрано й кілька налаштувань підказок (голос, частота, роль, таймери мапи).

  Без героїв, номерів матчів, текстів підказок, ніка, Steam ID і ключів. Це допоможе зрозуміти, які підказки приходять надто пізно. Під перемикачем «Що надсилається» показує точний текст надсилання. Рахувати починає з моменту ввімкнення; вимкнення одразу припиняє надсилання. Подробиці — на сторінці «Конфіденційність».
- **«Видалити мої дані на сервері».** Одна кнопка там само стирає із сервера все, що надсилав цей комп'ютер: звіти про проблеми, посилання «Поділитися» й статистику.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

**In English:**
- **Optional anonymous statistics** (Settings → App, off by default): once a day, how often each kind of advice was shown, how many urgent warnings came before a death within 30 s, how many matches were reviewed and a few advice settings. No heroes, match numbers, advice texts, nickname, Steam ID or keys. «What is sent» shows the exact body.
- **Delete my data on the server**: one button removes every problem report, shared link and statistics row this computer sent.
