## Что нового

- **Анонимная статистика — только если вы её включите.** В «Настройках → Приложение» появился переключатель «Анонимная статистика», по умолчанию он выключен. Если включить, раз в день приложение отправляет счётчики за прошлый день:
  - сколько раз тренер показал подсказку каждого типа;
  - после скольких срочных предупреждений в течение 30 секунд была смерть;
  - сколько матчей разобрано и несколько настроек подсказок (голос, частота, роль, таймеры карты).

  Без героев, номеров матчей, текстов подсказок, ника, Steam ID и ключей. Это поможет понять, какие подсказки приходят слишком поздно. Под переключателем «Что отправляется» показывает точный текст отправки. Считать начинает с момента включения; выключение сразу прекращает отправку. Подробности — на странице «Конфиденциальность».
- **«Удалить мои данные на сервере».** Одна кнопка там же стирает с сервера всё, что отправлял этот компьютер: отчёты о проблемах, ссылки «Поделиться» и статистику.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **Optional anonymous statistics** (Settings → App, off by default): once a day, how often each kind of advice was shown, how many urgent warnings came before a death within 30 s, how many matches were reviewed and a few advice settings. No heroes, match numbers, advice texts, nickname, Steam ID or keys. «What is sent» shows the exact body.
- **Delete my data on the server**: one button removes every problem report, shared link and statistics row this computer sent.
