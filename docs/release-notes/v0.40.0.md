## Что нового

- **Первое очко навыка.** Пока идёт подготовка к игре, карточка подскажет, с какого навыка начать: «Первое очко: Blade Fury — про-игроки на этом герое начинают с Blade Fury (3 из 3 игр)». Подсказка появляется, если вы ещё ничего не вкачали, а большинство игр про-игроков на этом герое начинаются с одного навыка. Раньше подсказки о прокачке появлялись только после начала игры, и про первый уровень их не было вовсе.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **The first skill point:** before the horn the card says which skill to start with — «First point: Blade Fury — pros on this hero start with Blade Fury (3 of 3 games)» — when you have learned nothing yet and most pro games on the hero open with the same skill. Skill tips used to wait for the horn and never covered level 1.
