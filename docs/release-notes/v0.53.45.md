## Что нового

- **База знаний читается один раз.** Приложение загружает Markdown при запуске; в режиме разработки изменения файлов обновляют кэш. Ошибка обновления сохраняет последний целый набор и отмечается в диагностике.
- **Меньше работы при повторных советах.** Ранние проверки scheduler отсекают повтор, cooldown и отсутствие совета до поиска контекста. Формулировки, фильтрация купленных предметов и правила советов сохранены.

---

**In English:**
- **Knowledge is loaded once.** Startup parses local Markdown; file changes refresh the development cache. Failed refresh keeps the last complete catalog and records diagnostics.
- **Less work for repeated advice.** Early duplicate, cooldown and no-advice checks run before context retrieval. Wording, owned-item filtering and advice policy remain unchanged.
