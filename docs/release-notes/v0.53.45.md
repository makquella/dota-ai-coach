## Що нового

- **База знань читається один раз.** Застосунок завантажує Markdown під час запуску; у режимі розробки зміни файлів оновлюють кеш. Помилка оновлення зберігає останній цілий набір і позначається в діагностиці.
- **Менше роботи під час повторних порад.** Ранні перевірки scheduler відсікають повтор, cooldown і відсутність поради до пошуку контексту. Формулювання, фільтрування куплених предметів і правила порад збережено.

---

**In English:**
- **Knowledge is loaded once.** Startup parses local Markdown; file changes refresh the development cache. Failed refresh keeps the last complete catalog and records diagnostics.
- **Less work for repeated advice.** Early duplicate, cooldown and no-advice checks run before context retrieval. Wording, owned-item filtering and advice policy remain unchanged.
