## Что нового

- **Отдельный модуль переводов экранов матчей.** RU/EN тексты вынесены из большого контроллера. Прежние тексты, склонения, форматирование чисел и переключение языка сохраняются и проверяются в настоящем интерфейсе.

---

**In English:**
- **An independent match-screen translation module.** RU/EN copy is separate from the large view controller. Existing copy, plurals, number formatting and language switching are preserved and checked in the actual interface.
