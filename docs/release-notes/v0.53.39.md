## Что нового

- **Контракты игровых данных и разбора.** Нормализованное состояние, факты матча и findings получили проверяемые типы. API разбора проверяет источник, значение, время и покрытие evidence, а также соответствие полю finding. Неизвестные значения, нули, старые поля и локализованные тексты сохраняются.
- **Проверка типов стала точнее.** Ошибочные ключи и значения в основных полях выявляются до выполнения; три прежние ошибки устранены без новых исключений.

---

**In English:**
- **Typed game data and review contracts.** Normalized state, match facts and finding cores have checked types. The review API validates measurement source, value, time, coverage and finding-field consistency, retaining unknown values, zero, legacy fields and localized text.
- **More precise type checking.** Invalid keys and values in core fields are caught before execution; three previous errors were removed without adding allowances.
