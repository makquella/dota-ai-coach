## Що нового

- **Контракти ігрових даних і розбору.** Нормалізований стан, факти матчу та findings отримали типи, що перевіряються. API розбору перевіряє джерело, значення, час і покриття evidence, а також відповідність полю finding. Невідомі значення, нулі, старі поля й локалізовані тексти зберігаються.
- **Перевірка типів стала точнішою.** Хибні ключі та значення в основних полях виявляються до виконання; три попередні помилки усунено без нових винятків.

---

**In English:**
- **Typed game data and review contracts.** Normalized state, match facts and finding cores have checked types. The review API validates measurement source, value, time, coverage and finding-field consistency, retaining unknown values, zero, legacy fields and localized text.
- **More precise type checking.** Invalid keys and values in core fields are caught before execution; three previous errors were removed without adding allowances.
