## Что нового

- **Сбои записи видны в диагностике.** Census подтверждает сохранение после успешной замены файла и повторяет неудачную попытку с паузой. Отладочная запись останавливается при ошибке, сохраняя уже записанные данные и live-ответы.
- **Настройки продолжают работать в памяти.** Ошибка файла не подтверждается как успешное сохранение; следующая правка может повторить запись. Диагностика содержит код ошибки и счётчики без значений настроек.

---

**In English:**
- **Write failures are visible in diagnostics.** Census acknowledges successful replacement and retries failed saves after a delay. Debug recording stops on failure while retaining written data and live responses.
- **Settings remain usable in memory.** Failed writes stay unacknowledged and a later edit can retry. Diagnostics retain safe error codes and counts without setting values.
