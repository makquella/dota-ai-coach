## Что нового

- **Прогресс получает проверяемый контракт данных.** Числа матчей и побед, серии, список героев и результаты проверяются по типам ответа. Неизвестный результат и отсутствующие средние сохраняются при выборе героя. Эти переходы проверяются на сохранённой истории через настоящий IPC на русском и английском.

---

**In English:**
- **Progress has a validated data contract.** Match and win counts, streaks, heroes and results use validated response types. Unknown results and missing averages remain intact when selecting a hero. Actual IPC checks exercise stored match history in Russian and English.
