## Що нового

- **Прогрес отримує контракт даних, що перевіряється.** Кількість матчів і перемог, серії, список героїв і результати перевіряються за типами відповіді. Невідомий результат і відсутні середні зберігаються під час вибору героя. Ці переходи перевіряються на збереженій історії через справжній IPC обома мовами.

**In English:**
- **Progress has a validated data contract.** Match and win counts, streaks, heroes and results use validated response types. Unknown results and missing averages remain intact when selecting a hero. Actual IPC checks exercise stored match history in Ukrainian and English.
