## Что нового

- **Отчёт о проблеме знает последний матч.** В отчёт добавлена короткая сводка о последнем матче, который записало приложение: герой, длительность, сколько записано точек, смертей и подсказок, готов ли разбор. Только числа — без ников и Steam ID. Так по отчёту, отправленному на следующий день, видно, была ли игра записана.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

---

**In English:**
- **The problem report knows the last match:** a short summary of the last match the app recorded — hero, length, how many samples, deaths and advice were recorded, whether its review is ready. Numbers only, no nicknames or Steam IDs, so a report sent the next day shows whether the game was recorded.
