## Что нового

- **Ключи зашифрованы на диске.** Ключ ИИ-тренера и ключ OpenDota в базе приложения, а также ссылка на канал Discord, токены удаления ссылок «Поделиться» и токен публичного профиля в настройках теперь хранятся зашифрованными средствами Windows (DPAPI) для вашей учётной записи. Скопированная папка с данными не даёт чужому человеку рабочих ключей.
- **Ничего вводить заново не нужно.** Ключи, сохранённые прошлыми версиями открытым текстом, шифруются сами при первом запуске. Если папку перенесли на другой компьютер или в другую учётную запись, ключ просто нужно ввести ещё раз — остальные данные не трогаются.
- **Проверено на Windows.** Сборка в CI теперь проверяет, что шифрование Windows работает и расшифровывает значение обратно.

---

**In English:**
- **Keys are encrypted on disk:** the AI coach and OpenDota keys in the app's database, plus the Discord channel link, the share-link delete tokens and the public profile token in the settings are now sealed with Windows DPAPI for your user account. A copied data folder gives nobody working keys.
- **Nothing to enter again:** keys saved in plain text by older versions are sealed automatically on the first start. If the folder moves to another computer or user account, just enter the key again; nothing else is touched.
- **Checked on Windows:** the CI build now proves that Windows encryption seals and opens a value back.
