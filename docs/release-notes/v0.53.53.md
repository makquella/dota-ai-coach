## Що нового

- **Ключі зашифровано на диску.** Ключ ШІ-тренера й ключ OpenDota в базі застосунку, а також посилання на канал Discord, токени видалення посилань «Поділитися» й токен публічного профілю в налаштуваннях тепер зберігаються зашифрованими засобами Windows (DPAPI) для вашого облікового запису. Скопійована тека з даними не дає сторонній людині робочих ключів.
- **Нічого вводити наново не потрібно.** Ключі, збережені попередніми версіями відкритим текстом, шифруються самі під час першого запуску. Якщо теку перенесли на інший комп'ютер чи в інший обліковий запис, ключ просто потрібно ввести ще раз — решту даних не зачеплено.
- **Перевірено на Windows.** Збірка в CI тепер перевіряє, що шифрування Windows працює й розшифровує значення назад.

---

**In English:**
- **Keys are encrypted on disk:** the AI coach and OpenDota keys in the app's database, plus the Discord channel link, the share-link delete tokens and the public profile token in the settings are now sealed with Windows DPAPI for your user account. A copied data folder gives nobody working keys.
- **Nothing to enter again:** keys saved in plain text by older versions are sealed automatically on the first start. If the folder moves to another computer or user account, just enter the key again; nothing else is touched.
- **Checked on Windows:** the CI build now proves that Windows encryption seals and opens a value back.
