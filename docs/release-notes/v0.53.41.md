## Что нового

- **API остаётся отзывчивым во время обработки игры.** Игровые пакеты и demo обрабатываются в рабочем потоке вместе с файловыми операциями; основной event loop освобождён.
- **Измерения live пути.** Локальный отчёт содержит ограниченные замеры подготовки, правил и сохранения, число выполняющихся операций и p50/p95. Пакеты и тексты советов не сохраняются в этих измерениях.

---

**In English:**
- **The API remains responsive during game processing.** Game packets and demo processing, including filesystem work, run on worker threads, freeing the API event loop.
- **Live-path measurements.** Local reports include bounded preparation, rules and persistence timings, running counts and p50/p95. These measurements retain no packets or advice text.
