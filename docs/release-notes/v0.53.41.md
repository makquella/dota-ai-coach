## Що нового

- **API залишається чуйним під час обробки гри.** Ігрові пакети й demo обробляються в робочому потоці разом із файловими операціями; основний event loop звільнено.
- **Вимірювання live-шляху.** Локальний звіт містить обмежені заміри підготовки, правил і збереження, кількість операцій, що виконуються, та p50/p95. Пакети й тексти порад у цих вимірюваннях не зберігаються.

---

**In English:**
- **The API remains responsive during game processing.** Game packets and demo processing, including filesystem work, run on worker threads, freeing the API event loop.
- **Live-path measurements.** Local reports include bounded preparation, rules and persistence timings, running counts and p50/p95. These measurements retain no packets or advice text.
