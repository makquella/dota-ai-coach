## Що нового

- **Запис матчу знову зберігається.** «Зберегти файл» у «Налаштування → Зберігати записи матчів тиждень» відмовляв із «Не вдалося зберегти файл»: застосунок просив запис у локального сервісу без свого ключа доступу. Тепер файл потрапляє в «Завантаження», а недокачаний файл не лишається.
- **Звіт про проблему без Steam id.** Номер акаунта лишався в назві задачі AI-тренера всередині звіту; тепер його замінено на «[id]», як і всюди у звіті.
- **Тихіший журнал оновлень.** Зникло зайве попередження «disableWebInstaller» при кожній перевірці оновлень.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

---

**In English:**
- **Match recordings save again.** «Save file» in Settings → Keep match recordings for a week failed with «Could not save the file»: the app asked the local service for the recording without its access key. The file now goes to Downloads, and a partial download is not left behind.
- **No Steam id in problem reports.** The account number stayed inside the AI coach job name in the report; it is now replaced with «[id]» like everywhere else in the report.
- **A quieter update log.** The needless «disableWebInstaller» warning on every update check is gone.
