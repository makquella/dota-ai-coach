## Що нового

- **Пам'ять підказок оновлюється послідовно.** Підказки мапи, прокачки й покупок більше не змінюють своїх лічильників одночасно з оновленням гри, скиданням чи іншим запитом оверлея. Якщо гра оновилася під час підготовки даних, застаріла підготовка пропускається до наступного опитування.

---

**In English:**
- **Tip memory updates sequentially.** Map, skill and shop tips no longer change their bookkeeping concurrently with a game update, reset or another overlay request. If the game changes during metadata preparation, stale preparation is skipped until the next poll.
