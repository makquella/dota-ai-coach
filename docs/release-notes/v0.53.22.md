## Что нового

- **Память подсказок обновляется последовательно.** Подсказки карты, прокачки и покупок больше не меняют свои счётчики одновременно с обновлением игры, сбросом или другим запросом оверлея. Если игра обновилась во время подготовки данных, устаревшая подготовка пропускается до следующего опроса.

---

**In English:**
- **Tip memory updates sequentially.** Map, skill and shop tips no longer change their bookkeeping concurrently with a game update, reset or another overlay request. If the game changes during metadata preparation, stale preparation is skipped until the next poll.
