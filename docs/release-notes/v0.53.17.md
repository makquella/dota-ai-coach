## Что нового

- **Неполный K/D/A сохраняет известные значения.** Ноль остаётся нулём; для каждого отсутствующего счётчика показывается прочерк. Разбор, таблица матчей и короткие сводки больше не выводят `null` и не скрывают смерти или ассисты при неизвестных убийствах.
- **Проверяемый контракт деталей матча.** API проверяет основные поля ответа и публикует их схему, сохраняя заметки, графики, разбор ИИ и остальные существующие разделы.

---

**In English:**
- **Partial K/D/A keeps known values.** Zero stays zero; each missing counter shows a dash. The review, match table and compact summaries no longer print `null` or hide known deaths/assists when kills are unknown.
- **A validated match-detail contract.** The API validates core response fields and publishes their schema while preserving notes, charts, AI reviews and other existing sections.
