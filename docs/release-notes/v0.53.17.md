## Що нового

- **Неповний K/D/A зберігає відомі значення.** Нуль залишається нулем; для кожного відсутнього лічильника показується прочерк. Розбір, таблиця матчів і короткі зведення більше не виводять `null` і не приховують смертей чи асистів за невідомих вбивств.
- **Контракт деталей матчу, що перевіряється.** API перевіряє основні поля відповіді й публікує їхню схему, зберігаючи нотатки, графіки, розбір ШІ та решту наявних розділів.

---

**In English:**
- **Partial K/D/A keeps known values.** Zero stays zero; each missing counter shows a dash. The review, match table and compact summaries no longer print `null` or hide known deaths/assists when kills are unknown.
- **A validated match-detail contract.** The API validates core response fields and publishes their schema while preserving notes, charts, AI reviews and other existing sections.
