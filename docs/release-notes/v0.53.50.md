## Что нового

- **Один источник героев.** Имя героя из игры, внутреннее имя (`npc_dota_hero_…`), его ключ и старое написание вроде «Nevermore» или «Furion» теперь распознаются одной функцией по общей таблице. Раньше у живой игры и у проверки героя были свои списки и своя догадка по написанию.
- **Проверка совпадения.** Новый тест сверяет таблицу героев с картинками лаунчера, профилями героев, правилами безопасности, сборками STRATZ и списком поддерживаемых героев.
- **Образы профиля одинаковы везде.** Тест Worker сравнивает каждое правило рамок, баннеров, ников и титулов публичной страницы с приложением, так что изменённый образ не разойдётся между ними.

---

**In English:**
- **One source for heroes:** the in-game name, the internal `npc_dota_hero_…` name, its key and old spellings such as «Nevermore» or «Furion» now resolve through one function over the shared table. The live game and the hero check used to keep their own lists and their own guess from the spelling.
- **Kept in step:** a new test checks the hero table against the launcher's pictures, hero profiles, safety rules, STRATZ builds and the supported list.
- **Profile looks match everywhere:** a Worker test compares every frame, banner, name and title rule of the public page with the app, so a changed look cannot drift between them.
