## Що нового

- **Нове навчання.** Навчання під час першого запуску тепер показує справжні картки порад і пояснює, що означає кожен рядок: що робити, чому, що таке «Терміново». Окремо — підказки по мапі (руни, Рошан, «суперник зник»), план на гру, екран смерті й підсумок матчу, профіль із друзями, ШІ-тренер і допомога. Якщо ви вже пройшли старе навчання, відкрийте нове: «Налаштування → Допомога → Показати».

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

- **A new first-run tour:** real advice cards with what each line means, map calls (runes, Roshan, an enemy missing), the game plan, the death screen and the score card, the profile and friends, the AI coach and help. Already took the old tour? Open the new one in Settings → Help → «Show».
