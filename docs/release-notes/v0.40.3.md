## Что нового

- **Новое обучение.** Обучение при первом запуске теперь показывает настоящие карточки советов и объясняет, что значит каждая строка: что делать, почему, что такое «Срочно». Отдельно — подсказки по карте (руны, Рошан, «соперник пропал»), план на игру, экран смерти и итог матча, профиль с друзьями, ИИ-тренер и помощь. Если вы уже прошли старое обучение, откройте новое: «Настройки → Помощь → Показать».

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.

**In English:**
- **A new first-run tour:** real advice cards with what each line means, map calls (runes, Roshan, an enemy missing), the game plan, the death screen and the score card, the profile and friends, the AI coach and help. Already took the old tour? Open the new one in Settings → Help → «Show».
