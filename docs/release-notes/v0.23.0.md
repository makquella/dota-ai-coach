## Що нового

- **Куди вкласти очко.** Тренер знає, як прокачують героя про-гравці (останні про-матчі на цьому герої): після нового рівня він називає вміння — «Вкладіть очко в Blade Fury» — і показує весь порядок прокачки. Ультимейт тепер називається так само, як у грі.
- **Прокачка в плані на гру.** На початку матчу — рядок «Прокачка в про: спершу …, потім …».
- **Прокачка в розборі.** Якщо першим ви прокачали до кінця не те вміння, що про-гравці на цьому герої, розбір скаже про це й підкаже, з чого почати наступного разу.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.

**In English:**
- **Where the point goes:** the coach knows how pro players level your hero (recent pro games) and names the skill after a level-up — «Put the point in Blade Fury» — with the whole order. The ultimate now has its in-game name.
- **The skill order in the game plan:** «Pros max … first, then …» at the start of a match.
- **The skill order in the review:** when you maxed a different skill first than pros on the hero, the review says so and what to start with next time.
