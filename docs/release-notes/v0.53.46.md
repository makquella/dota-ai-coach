## Що нового

- **Історію порад захищено від гонок.** Одночасні повтори додають одну картку; reset відхиляє підготовлений запис старої сесії. Запит останніх порад копіює лише потрібні записи.
- **Переклад за ID і параметрами.** Live-картки зберігають англійський оригінал і отримують опис тексту. Незмінені повторні запити використовують обмежений кеш; невідомі фрази залишаються англійською повністю.

---

**In English:**
- **Advice history handles concurrent changes.** Simultaneous duplicates add one card, reset rejects old prepared appends, and recent requests copy only their selected records.
- **Translation uses IDs and parameters.** Live cards preserve canonical English and include message descriptors. Unchanged polls reuse bounded caches; unknown phrases remain wholly English.
