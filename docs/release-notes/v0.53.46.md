## Что нового

- **История советов защищена от гонок.** Одновременные повторы добавляют одну карточку; reset отклоняет подготовленную запись старой сессии. Запрос последних советов копирует только нужные записи.
- **Перевод по ID и параметрам.** Live-карточки сохраняют английский оригинал и получают описание текста. Неизменённые повторные запросы используют ограниченный кэш; неизвестные фразы остаются на английском целиком.

---

**In English:**
- **Advice history handles concurrent changes.** Simultaneous duplicates add one card, reset rejects old prepared appends, and recent requests copy only their selected records.
- **Translation uses IDs and parameters.** Live cards preserve canonical English and include message descriptors. Unchanged polls reuse bounded caches; unknown phrases remain wholly English.
