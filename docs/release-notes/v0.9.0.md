## Что нового

- **Статус в Discord.** Пока запущена Дота, в вашем профиле Discord видно «В меню Dota 2» или «Матч на Juggernaut · с тренером Wardly» со временем матча и кнопкой на сайт Wardly. Статус передаётся только программе Discord на вашем компьютере, нам ничего не отправляется. Выключается в «Настройках → Приложение → Статус в Discord».
- **Короткие ссылки.** «Поделиться разбором» и «Поделиться прогрессом» теперь дают ссылки вида `luhovyimvp.dev/r/…`. Старые ссылки на `api.luhovyimvp.dev` продолжают работать.
- **Сайт и страницы разборов в цветах логотипа** — красный вместо жёлтого.

Установщик пока без цифровой подписи: если Windows покажет «Windows защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установленная версия обновится сама, когда Дота будет закрыта.
