## Що нового

- **Статус у Discord.** Поки запущена Дота, у вашому профілі Discord видно «У меню Dota 2» або «Матч на Juggernaut · з тренером Wardly» з часом матчу й кнопкою на сайт Wardly. Статус передається лише програмі Discord на вашому комп'ютері, нам нічого не надсилається. Вимикається в «Налаштуваннях → Застосунок → Статус у Discord».
- **Короткі посилання.** «Поділитися розбором» і «Поділитися прогресом» тепер дають посилання вигляду `luhovyimvp.dev/r/…`. Старі посилання на `api.luhovyimvp.dev` продовжують працювати.
- **Сайт і сторінки розборів у кольорах логотипа** — червоний замість жовтого.

Інсталятор поки без цифрового підпису: якщо Windows покаже «Windows захистив ваш комп'ютер», натисніть «Докладніше» → «Однаково запустити». Встановлена версія оновиться сама, коли Дота буде закрита.
