## Что нового

- **Надёжнее перенос истории по коду.** Одновременные запросы теперь соблюдают лимит скачиваний. Если два переноса выбрали один короткий ID, сохраняется первый файл, а второй получает обычный ответ о занятом коде.
- **Новый перенос защищён от поздней очистки старого.** Запрос от завершённого или истёкшего переноса не удалит свежий файл, который уже занял тот же ID.

---

**In English:**
- **More reliable history transfer by code.** Concurrent requests now respect the download limit. If two transfers choose the same short ID, the first file is preserved and the second gets the normal code-in-use response.
- **Fresh transfers survive late cleanup.** A request from a finished or expired transfer cannot delete a new file that has reused the same ID.
