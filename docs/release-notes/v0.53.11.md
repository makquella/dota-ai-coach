## Що нового

- **Надійніше перенесення історії за кодом.** Одночасні запити тепер дотримуються ліміту завантажень. Якщо два перенесення вибрали один короткий ID, зберігається перший файл, а другий отримує звичайну відповідь про зайнятий код.
- **Нове перенесення захищене від пізнього очищення старого.** Запит від завершеного чи простроченого перенесення не видалить свіжий файл, який уже зайняв той самий ID.

---

**In English:**
- **More reliable history transfer by code.** Concurrent requests now respect the download limit. If two transfers choose the same short ID, the first file is preserved and the second gets the normal code-in-use response.
- **Fresh transfers survive late cleanup.** A request from a finished or expired transfer cannot delete a new file that has reused the same ID.
