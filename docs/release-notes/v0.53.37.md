## Что нового

- **Данные профиля проходят проверяемый контракт API.** Основные поля игрока, уровня, статистики, искр и графика рейтинга сохраняют неизвестные значения, нули и оценки со знаком. Чтение профиля, сохранение/сброс MMR и ответы магазина возвращают ту же полную структуру с наградами и оформлением; строки и некорректные числа в основных полях отклоняются.

---

**In English:**
- **Profile data has a validated API contract.** Core player, level, statistics, sparks and rating-graph fields preserve unknown values, zero and signed estimates. Profile reads, MMR save/clear and shop responses retain the complete structure, including achievements and cosmetics; core fields reject numeric strings and invalid numbers.
