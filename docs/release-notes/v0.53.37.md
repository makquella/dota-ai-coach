## Що нового

- **Дані профілю проходять контракт API, що перевіряється.** Основні поля гравця, рівня, статистики, іскор і графіка рейтингу зберігають невідомі значення, нулі й оцінки зі знаком. Читання профілю, збереження/скидання MMR і відповіді крамниці повертають ту саму повну структуру з нагородами й оформленням; рядки й некоректні числа в основних полях відхиляються.

---

**In English:**
- **Profile data has a validated API contract.** Core player, level, statistics, sparks and rating-graph fields preserve unknown values, zero and signed estimates. Profile reads, MMR save/clear and shop responses retain the complete structure, including achievements and cosmetics; core fields reject numeric strings and invalid numbers.
