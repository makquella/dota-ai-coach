## Що нового

- **Налагоджувальні сторінки відокремлено від застосунку.** Старі браузерні сторінки (форма сценарію та простий оверлей) переїхали до `frontend/debug/`, відкриваються за адресою `/debug/` лише з вихідного коду й підписані як налагоджувальні. Встановлений застосунок їх не віддає.
- **Менше відкритого назовні.** Бекенд більше не роздає решти вмісту теки `frontend/` (вихідний код лаунчера); без токена доступні лише самі налагоджувальні сторінки.

---

**In English:**
- **Debug pages are separated from the app:** the legacy browser pages moved to `frontend/debug/`, are served at `/debug/` from a source checkout only and are labelled as debug pages; the installed app never serves them.
- **Less exposed:** the backend no longer serves the rest of `frontend/` (the launcher's sources); only the debug pages themselves load without a token.
