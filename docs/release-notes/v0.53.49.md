## Что нового

- **Отладочные страницы отделены от приложения.** Старые браузерные страницы (форма сценария и простой оверлей) переехали в `frontend/debug/`, открываются по адресу `/debug/` только из исходников и подписаны как отладочные. Установленное приложение их не отдаёт.
- **Меньше открытого наружу.** Бэкенд больше не раздаёт остальное содержимое папки `frontend/` (исходники лаунчера); без токена доступны только сами отладочные страницы.

---

**In English:**
- **Debug pages are separated from the app:** the legacy browser pages moved to `frontend/debug/`, are served at `/debug/` from a source checkout only and are labelled as debug pages; the installed app never serves them.
- **Less exposed:** the backend no longer serves the rest of `frontend/` (the launcher's sources); only the debug pages themselves load without a token.
