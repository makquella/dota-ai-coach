# Пошук перших гравців: план

Мета першого місяця — **100 встановлень від гравців з України** і чесний зворотний зв'язок.
Wardly повністю українською (застосунок, підказки, голос, розбори, сайт), тож це
головна перевага перед англомовними тренерами. Англомовні майданчики (Reddit,
Hacker News) — у другу хвилю, коли будуть перші відгуки й підпис інсталятора.

Готові тексти — [posts.md](posts.md), сценарій ролика — [video.md](video.md), вітрина на GitHub — [github.md](github.md).

## 2. Посилання з міткою джерела

Завжди давайте посилання **на сайт із міткою**, а не пряме на інсталятор: сайт
пояснює, що це, а мітка показує, звідки прийшли (в `/admin` → «Звідки приходять»).

| Майданчик | Посилання |
|---|---|
| Гайд у Steam | `https://luhovyimvp.dev/?ref=steam` |
| Telegram (свій допис або канал) | `https://luhovyimvp.dev/?ref=tg` — для конкретного каналу `?ref=tg-<назва>` |
| Discord-сервери | `?ref=discord` (для конкретного сервера `?ref=discord-<назва>`) |
| Instagram / Threads / X | `?ref=social` |
| YouTube / Shorts | `https://luhovyimvp.dev/?ref=yt` |
| TikTok / Reels | `?ref=tiktok` / `?ref=reels` |
| Twitch-стримери | `?ref=twitch-<нік>` |
| DOU | `?ref=dou` |

Для англомовних майданчиків — та сама мітка на англійській версії: `https://luhovyimvp.dev/en/?ref=reddit`. Сторінки героїв теж приймають мітку (`/heroes/axe.html?ref=tg`) — зручно для дописів про конкретного героя.

Мітка — латиниця, цифри, `-` і `_`, до 24 символів. Без мітки сайт сам
визначить пошук (`search`), відомі сайти (reddit, tg, yt, steam, twitch, discord,
github та інші), прочі (`other`) і прямий захід (`direct`). Посилання «Відкрити у
Wardly» зі сторінок розборів приходять як `share`.

## 3. Порядок запуску (по тижню на крок, щоб бачити ефект кожного)

1. **Гайд у Steam** українською (`posts.md` → «Гайд у Steam»). Живе роками,
   знаходиться в Google і в спільноті Dota 2. Заразом це інструкція зі
   встановлення, на яку можна посилатися з коментарів.
2. **Telegram** — українські канали й чати про Доту та кіберспорт: історія з
   роликом у свій канал, гостьовий допис у невеликих каналах (5–50 тис.
   підписників), короткий допис у чатах, де це дозволено. Найкращий час — вечір
   буднього дня (19:00–22:00 за київським часом).
3. **Discord** — українські сервери спільнот Dota 2, лише в каналах для
   самопіару; спершу правила сервера.
4. **Стримери й короткі відео** — українські стримери на Twitch, автори на
   YouTube і TikTok: безкоштовний огляд (застосунок безкоштовний і відкритий —
   це не реклама за гроші). Свій ролик — у Shorts, TikTok і Reels.
5. **DOU** (за бажанням) — технічна розповідь для розробників: GSI, правила
   замість «ШІ вирішує», перевірка кожної цифри в ШІ-розборі, українська через
   ID повідомлень. Гравців дає мало, але дає зірки на GitHub і довіру.
6. **Друга хвиля, англомовна** (після підпису інсталятора й перших відгуків):
   r/learndota2, потім r/DotA2 (суворі правила щодо самопіару — лише у форматі
   «зробив безкоштовний інструмент із відкритим кодом, ось як працює»), Show HN.

## 4. Як поводитися в коментарях

- Відповідати в перші 2–3 години — це піднімає допис і знімає сумніви.
- Жодних накруток, фейкових відгуків і «я просто знайшов класну програму» з
  другого акаунта: спільноти це вираховують, і довіра зникає.
- Чесно говорити про обмеження: повні підказки поки для 64 героїв, інсталятор
  без підпису, ШІ-розбір потребує свого безкоштовного ключа Gemini, голос
  українською потребує голосу Windows (інакше читає англійською).
- Будь-яку знайдену помилку — в issues на GitHub і у відповідь: «дякую, виправлю в
  наступній версії» (і справді виправити: оновлення прийде саме).
- Готові відповіді на часті запитання — наприкінці `posts.md`.

## 5. Що рахувати й коли

Раз на тиждень дивитися `/admin` → «Звідки приходять» і «За днями»:

- **Заходи** за джерелом — скільки людей дійшло до сайту.
- **Завантаження** й **конверсія** — скільки з них завантажили. Менше 10 % —
  сайт чи допис обіцяє не те; понад 25 % — канал добрий, варто повторити.
- **Пристрої** (анонімна статистика, за згодою) — скільки реально грають.
- Завантаження на GitHub — повна цифра, зокрема прямі посилання.

Рішення після кожного каналу: повторити (конверсія й відгуки добрі), змінити
подачу (заходи є, завантажень немає) або кинути (заходів немає).
