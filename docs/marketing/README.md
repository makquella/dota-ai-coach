# Поиск первых игроков: план

Цель первого месяца — **100 установок от игроков СНГ** и честная обратная связь.
Англоязычные площадки (Reddit, Hacker News) — во вторую волну, когда будут
первые отзывы и подпись установщика.

Готовые тексты — [posts.md](posts.md), сценарий ролика — [video.md](video.md).

## 2. Ссылки с меткой источника

Всегда давайте ссылку **на сайт с меткой**, а не прямую на установщик: сайт
объясняет, что это, а метка показывает, откуда пришли (в `/admin` → «Откуда приходят»).

| Площадка | Ссылка |
|---|---|
| Гайд в Steam | `https://luhovyimvp.dev/?ref=steam` |
| Pikabu | `https://luhovyimvp.dev/?ref=pikabu` |
| DTF | `https://luhovyimvp.dev/?ref=dtf` |
| Хабр | `https://luhovyimvp.dev/?ref=habr` |
| Telegram (свой пост или канал) | `https://luhovyimvp.dev/?ref=tg` — для конкретного канала `?ref=tg-<название>` |
| ВКонтакте | `https://luhovyimvp.dev/?ref=vk` |
| YouTube / Shorts | `https://luhovyimvp.dev/?ref=yt` |
| VK Клипы / TikTok | `?ref=vkclips` / `?ref=tiktok` |
| Discord-серверы | `?ref=discord` |

Метка — латиница, цифры, `-` и `_`, до 24 символов. Без метки сайт сам
определит поиск (`search`), известные сайты (reddit, pikabu, dtf, vk, tg, yt,
steam, twitch, discord, github, cybersport), прочие (`other`) и прямой заход
(`direct`). Ссылки «Открыть в Wardly» со страниц разборов приходят как `share`.

## 3. Порядок запуска (по неделе на шаг, чтобы видеть эффект каждого)

1. **Гайд в Steam** (`posts.md` → «Гайд в Steam»). Живёт годами, находится в
   Google и в сообществе Dota 2. Заодно это инструкция по установке, на которую
   можно ссылаться из комментариев.
2. **Pikabu** — пост-история с гифкой/роликом, теги `Dota 2`, `Игры`, `Моё`.
   Лучшее время — вечер будней по Москве (19:00–22:00).
3. **DTF** — тот же рассказ в подсайт «Игры» или «Dota 2», больше про то, как
   устроено.
4. **Telegram и ВК** — короткий пост + ролик. Небольшим каналам про Доту
   (5–50 тыс. подписчиков) можно предложить бесплатный обзор: приложение бесплатное
   и с открытым кодом, это не реклама за деньги — многие соглашаются.
5. **Хабр** (по желанию) — технический рассказ: GSI, правила вместо «ИИ решает»,
   проверка каждой цифры в ИИ-разборе. Игроков даёт мало, но даёт звёзды на
   GitHub и доверие («код открыт, люди смотрели»).
6. **Вторая волна, англоязычная** (после подписи установщика и первых отзывов):
   r/learndota2, затем r/DotA2 (строгие правила про самопиар — только в формате
   «сделал бесплатный инструмент с открытым кодом, вот как работает»), Show HN.

## 4. Как вести себя в комментариях

- Отвечать в первые 2–3 часа — это поднимает пост и снимает сомнения.
- Никаких накруток, фейковых отзывов и «я просто нашёл классную программу» от
  второго аккаунта: на Pikabu и DTF это вычисляют, и пост уходит в минус.
- Честно говорить об ограничениях: полные подсказки пока для 39 героев, установщик
  без подписи, ИИ-разбор требует своего бесплатного ключа Gemini.
- Любую найденную ошибку — в issues на GitHub и в ответ: «спасибо, исправлю в
  следующей версии» (и правда исправить: обновление придёт само).
- Готовые ответы на частые вопросы — в конце `posts.md`.

## 5. Что считать и когда

Раз в неделю смотреть `/admin` → «Откуда приходят» и «По дням»:

- **Заходы** по источнику — сколько людей дошло до сайта.
- **Скачивания** и **конверсия** — сколько из них скачали. Меньше 10 % —
  сайт или пост обещает не то; больше 25 % — канал хороший, стоит повторить.
- **Устройства** (анонимная статистика, по согласию) — сколько реально играют.
- Скачивания на GitHub — полная цифра, включая прямые ссылки.

Решение после каждого канала: повторить (конверсия и отзывы хорошие), изменить
подачу (заходы есть, скачиваний нет) или бросить (заходов нет).
