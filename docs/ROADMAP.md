# План развития

Состояние на сентябрь 2026 года, версия **0.6.0** (приложение называется Wardly). Хранение данных пользователей
(отчёты о проблемах, статистика, общий кэш OpenDota, ссылки на разбор) описано
отдельно: [DATA_PLAN.md](DATA_PLAN.md).

## Что уже есть

- **Во время игры.**
  - Подсказки поверх Доты и голосом по официальной интеграции Valve (GSI):
    мало HP, фарм, ТП, золото после смерти, байбэк.
  - План на игру в начале матча.
  - Полный советник для 21 керри, на остальных героях — подсказки по выживанию.
  - Роль определяется по линии в первые минуты (или выбирается в настройках);
    таймеры карты за 20 секунд по данным патча (`data/meta/map_timers.json`),
    подсказки саппорту (стаки, варды, добивания), ТП на любом герое.
- **После игры.**
  - Разбор каждого матча (GSI + OpenDota): оценка по разделам, карта на
    настоящей миникарте Доты, смерти с контекстом, темп по добиваниям, золоту и
    опыту, сборка с процентом побед по времени покупки, драфт, сравнение с
    игроком того же ранга, отметка повторяющихся ошибок.
  - Итоги недели на главной и план на 3 матча по фокусу.
  - Фокус на одной ошибке, прогресс, ИИ-тренер с проверкой фактов,
    «Спросить тренера».
- **Приложение.**
  - Установщик для Windows с автообновлением.
  - Портреты героев и иконки предметов.
  - Отчёт о проблеме: файлом или одной кнопкой разработчику (Cloudflare
    Worker, этап 1 из DATA_PLAN).
  - Сайт https://luhovyimvp.dev.

## Принципы

1. **Числа — только из правил.** ИИ пересказывает, но не придумывает. Каждое новое
   правило получает тест и русский текст.
2. **Одна подсказка — одно действие.** Новые советы не должны отвлекать:
   планировщик и частота советов остаются главными.
3. **Всё работает без сети и без аккаунтов.** Облако — только по согласию и
   только для того, без чего нельзя (см. DATA_PLAN.md).
4. **Никакого чтения памяти и управления героем.** Только GSI и открытые API.

## Ближайшее: 0.2.x — стабильность на настоящих матчах

| Что | Зачем | Объём |
|---|---|---|
| Проверка на живых матчах у 5–10 тестеров: запись сессий GSI по согласию (запись уже есть в «Для разработчиков») и разбор, где совет был лишним или опоздал | Правила пока проверены на симуляциях и одном аккаунте | 1–2 недели наблюдений |

| Таймеры карты: сверять `map_timers.json` с каждым патчем (номер патча в файле) | Тайминги меняются почти каждый крупный патч | 15 минут на патч |
| Доступность сайта из России: сайт за прокси Cloudflare, а его в 2025 году замедляли российские провайдеры. Проверить у тестеров; если не открывается — перевести записи в «DNS only» | Основная аудитория русскоязычная | 1 час |

## 0.3 — подсказки для любой роли

**Сделано в 0.3.0:** таймеры карты по данным патча, роль по линии и в
настройках, подсказки саппорту (стаки, варды, «оставьте добивания керри»), ТП
на любом герое, советы про фарм на саппорте выключены. «Отправить
разработчику», драфт по позиции, еженедельное обновление `dota-data.js`.

**Осталось в 0.3.x:**
- Мид: ротация после руны силы (в GSI не видно, взята ли руна — только по
  бутылке), давление на вышки.
- Оффлейн: когда давить, когда уходить в лес.
- Проверить определение роли на живых матчах (запись сессий GSI).

Исходный план этапа:

- **Таймеры по часам матча**, как «Map Timers» у iTero: руны силы и богатства,
  руны мудрости, лотосы, Торментор, нейтральные предметы, шард. GSI даёт время
  матча, а правила хранятся в данных с номером патча, чтобы их можно было
  обновлять без правок кода. Подсказывать за 15–20 секунд до события и только
  тем ролям, кому оно нужно.
- **Саппорт:** напоминание о вардах и сентри (в GSI есть слоты предметов),
  стаки для своего керри, «не забирай волну у керри», дымка перед целью.
- **Мид и оффлейн:** руны, ротации после руны, давление на вышки, когда керри
  врага далеко от линии.
- **Роль определяется сама** по герою и первым минутам (кто на какой линии);
  в настройках её можно поправить.
- Оценка разбора и цели под роль. В `post_match_analysis` уже есть цели
  для core, offlane и support, их нужно довести до живых советов.

Готово, когда на любом из 127 героев игрок получает хотя бы 3–5 полезных
подсказок за матч, а срочные советы по выживанию работают как раньше.

## 0.4 — разбор глубже

**Сделано в 0.4.0:** настоящая миникарта Доты в разборе (путь, линия, варды,
смерти; места смертей из командных драк реплея), «хороший темп» по золоту и
опыту на графике, карточка «Смерти» (где, кто убил, непотраченное золото,
подсказка перед смертью, смерть сразу после возрождения), повторяющиеся ошибки
(«3-й матч подряд»), итоги недели и план по фокусу, ИИ-тренер видит повторы и
смерти, ночной фаззинг живых данных GSI.

**Осталось в 0.4.x:** нормы по рангу игрока (сейчас — бенчмарки OpenDota по
герою и цели роли), «сколько врагов было не видно» перед смертью (в GSI этого
нет — только из реплея), ответы ИИ-тренера про героя и контрпики.

Исходный план этапа:

- **Смерти с контекстом.** По записи GSI уже известны место смерти, золото и
  здоровье перед смертью. Добавить: была ли подсказка, сколько врагов было не
  видно, был ли у героя путь отхода.
- **Недельные итоги.** Раз в неделю карточка на главной: матчи, средняя оценка,
  прогресс по фокусу, лучший матч.
- **Тренировочный план.** Фокус → 3 матча с конкретным упражнением → проверка
  по цифрам. Продолжение механики фокуса.
- **Нормы по рангу и герою.** Брать бенчмарки OpenDota по брекету игрока, а не
  общие цели роли.
- **ИИ-тренер:** контекст прошлых разборов («третий матч подряд теряете линию»),
  ответы про героя и контрпики с проверкой фактов.

## 0.8 — смерти и решения

**Сделано в 0.8.0:** последние 20 секунд перед каждой смертью (здоровье,
контроль, спасающие предметы, которые были готовы; советы «Спасающий предмет не
нажат» и «Быстрые смерти»), ваш билд на герое на «Прогрессе» (процент побед с
предметом и без, тайминги в победах и поражениях), итог матча в оверлее на
экране со счётом, звание во времени, перенос истории по одноразовому коду с
шифрованием на стороне приложения.

**Дальше:**
- Discord Rich Presence — нужен Application ID.
- Проверка последних секунд перед смертью на живых матчах (данные GSI о
  предметах: `can_cast`, `cooldown`, `charges`).

## 0.5 — вместе с другими

**Сделано в 0.5.0:** новое имя Wardly и логотип; сравнение с другом по его
открытым матчам OpenDota («Прогресс»); «Поделиться разбором» — страница
`api.luhovyimvp.dev/r/<id>` с превью для Discord и Telegram, без номера матча,
Steam ID и ников, 90 дней, удаляется автором (этап 4 из DATA_PLAN); история
матчей в файл и обратно («Настройки → Приложение»), без ключей.

**Осталось в 0.5.x:**
- Ссылка вида `luhovyimvp.dev/r/<id>`: маршрут Worker на домен сайта в Cloudflare
  (Workers Routes), сейчас страница живёт на `api.luhovyimvp.dev/r/<id>`.
- Перенос истории по одноразовому коду через облако (сейчас — файлом).
- Discord: статус «играет с Wardly» (Rich Presence) — нужен Application ID
  приложения Discord; бот с итогами недели.

Исходный план этапа:

- **«Поделиться разбором»:** публичная ссылка вида `luhovyimvp.dev/r/<id>`,
  без Steam ID и ников, живёт 90 дней. Это ещё и бесплатное продвижение.
- **Сравнение с другом:** два игрока в одной роли, их средние цифры.
- **Резервная копия и перенос истории** на другой компьютер по одноразовому
  коду.
- **Discord:** статус «играю с тренером» (Rich Presence) и бот с итогами недели.

## Не делаем

- Чтение памяти игры, внедрение в процесс, автоматический ввод. Это риск бана
  и нарушение правил Valve.
- Платные функции, пока нет стабильной аудитории.
- Свой разбор реплеев на сервере: это дорого, а OpenDota разбирает реплеи
  бесплатно.
