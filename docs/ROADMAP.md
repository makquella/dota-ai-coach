# План развития

Состояние на сентябрь 2026 года, версия **0.2.1**. Хранение данных пользователей
(отчёты о проблемах, статистика, общий кэш OpenDota, ссылки на разбор) описано
отдельно: [DATA_PLAN.md](DATA_PLAN.md).

## Что уже есть

- **Во время игры.**
  - Подсказки поверх Доты и голосом по официальной интеграции Valve (GSI):
    мало HP, фарм, ТП, золото после смерти, байбэк.
  - План на игру в начале матча.
  - Полный советник для 21 керри, на остальных героях — подсказки по выживанию.
- **После игры.**
  - Разбор каждого матча (GSI + OpenDota): оценка по разделам, карта, сборка с
    процентом побед по времени покупки, драфт, сравнение с игроком того же ранга.
  - Фокус на одной ошибке, прогресс, ИИ-тренер с проверкой фактов,
    «Спросить тренера».
- **Приложение.**
  - Установщик для Windows с автообновлением.
  - Портреты героев и иконки предметов.
  - Отчёт о проблеме одним файлом.
  - Сайт https://luhovyimvp.dev.

## Принципы

1. **Числа — только из правил.** ИИ пересказывает, но не придумывает. Каждое новое
   правило получает тест и русский текст.
2. **Одна подсказка — одно действие.** Новые советы не должны отвлекать:
   планировщик и частота советов остаются главными.
3. **Всё работает без сети и без аккаунтов.** Облако — только по согласию и
   только для того, без чего нельзя (см. DATA_PLAN.md).
4. **Никакого чтения памяти и управления героем.** Только GSI и открытые API.

## 0.3 — подсказки для любой роли

Сейчас полный советник есть только для керри. На остальных героях приложение
почти молчит.

- **Таймеры по часам матча**, как «Map Timers» у iTero: руны силы и богатства,
  руны мудрости, лотосы, Торментор, нейтральные предметы, шард. GSI даёт время
  матча, а правила хранятся в данных с номером патча, чтобы их можно было
  обновлять без правок кода. Подсказывать за 15–20 секунд до события и только
  тем ролям, кому оно нужно.
- **Саппорт:** напоминание о вардах и сентри (в GSI есть слоты предметов),
  стаки для своего керри, «не забирай волну у керри», дымка перед целью.
- **Мид и оффлейн:** руны, ротации после руны, давление на вышки, когда керри
  врага далеко от линии.
- **Роль определяется сама** по герою и первым минутам (кто на какой линии);
  в настройках её можно поправить.
- Оценка разбора и цели под роль. В `post_match_analysis` уже есть цели
  для core, offlane и support, их нужно довести до живых советов.

Готово, когда на любом из 127 героев игрок получает хотя бы 3–5 полезных
подсказок за матч, а срочные советы по выживанию работают как раньше.

## 0.4 — разбор глубже

- **Смерти с контекстом.** По записи GSI уже известны место смерти, золото и
  здоровье перед смертью. Добавить: была ли подсказка, сколько врагов было не
  видно, был ли у героя путь отхода.
- **Недельные итоги.** Раз в неделю карточка на главной: матчи, средняя оценка,
  прогресс по фокусу, лучший матч.
- **Тренировочный план.** Фокус → 3 матча с конкретным упражнением → проверка
  по цифрам. Продолжение механики фокуса.
- **Нормы по рангу и герою.** Брать бенчмарки OpenDota по брекету игрока, а не
  общие цели роли.
- **ИИ-тренер:** контекст прошлых разборов («третий матч подряд теряете линию»),
  ответы про героя и контрпики с проверкой фактов.

## 0.5 — вместе с другими

Для этого этапа нужно облако из DATA_PLAN (этапы 3–4).

- **«Поделиться разбором»:** публичная ссылка вида `luhovyimvp.dev/r/<id>`,
  без Steam ID и ников, живёт 90 дней. Это ещё и бесплатное продвижение.
- **Сравнение с другом:** два игрока в одной роли, их средние цифры.
- **Резервная копия и перенос истории** на другой компьютер по одноразовому
  коду.
- **Discord:** статус «играю с тренером» (Rich Presence) и бот с итогами недели.

## Не делаем

- Чтение памяти игры, внедрение в процесс, автоматический ввод. Это риск бана
  и нарушение правил Valve.
- Платные функции, пока нет стабильной аудитории.
- Свой разбор реплеев на сервере: это дорого, а OpenDota разбирает реплеи
  бесплатно.
