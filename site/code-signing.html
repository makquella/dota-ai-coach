Code signing policy · оновлено 10 жовтня 2026 року

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Заявку до SignPath Foundation подано. Доки її не схвалено, інсталятор Wardly для Windows без цифрового підпису: Windows може показати «Windows захистив ваш комп'ютер». Кожен інсталятор має звіт VirusTotal в описі релізу.

Що підписується

  • Лише інсталятор Wardly для Windows і програма в ньому, зібрані з відкритого коду цього репозиторію (ліцензія MIT).
  • Збірка автоматична: GitHub Actions (.github/workflows/release.yml) збирає інсталятор з коду релізного коміту. Скрипти збірки й налаштування CI — частина того самого відкритого коду.
  • Назва продукту в метаданих файлів — Wardly, версія однакова для всіх файлів одного релізу.
  • Кожен підпис потребує ручного схвалення відповідальної особи (approver). Сторонні бінарні файли не підписуються від імені проєкту.

Ролі

  • Автори й рецензенти (committers and reviewers): makquella. Зміни від інших людей (pull requests) потрапляють у код лише після перевірки.
  • Схвалення підпису (approvers): makquella — власник репозиторію.
  • Для доступу до репозиторію й SignPath використовується двофакторна автентифікація.

Конфіденційність

Що Wardly зберігає на комп'ютері, що й коли надсилає (OpenDota, Valve CDN, GitHub, необов'язкові ШІ-сервіси, звіти й анонімна статистика лише за вашою згодою) і як це вимкнути — на сторінці Конфіденційність.

Видалення

Wardly видаляється як звичайна програма: «Параметри Windows → Програми → Wardly → Видалити».

Code signing policy

Updated 10 October 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

The application to SignPath Foundation has been submitted. Until it is approved, the Wardly installer for Windows is unsigned and Windows may show “Windows protected your PC”. Every installer has a VirusTotal report in its release notes.

What is signed

  • Only the Wardly installer for Windows and the app inside it, built from the open source code of this repository (MIT licence).
  • Builds are automated: GitHub Actions (.github/workflows/release.yml) builds the installer from the release commit. Build scripts and CI configuration are part of the same open source code.
  • The product name in the file metadata is Wardly, and the version is the same for every file of a release.
  • Every signing request is approved manually by an approver. Third-party binaries are never signed in the project's name.

Team roles

  • Committers and reviewers: makquella. Changes from anyone else (pull requests) are reviewed before they are merged.
  • Approvers: makquella, the repository owner.
  • Multi-factor authentication is used for access to the repository and to SignPath.

Privacy policy

What Wardly keeps on your computer, what it sends and when (OpenDota, Valve CDN, GitHub, optional AI services, problem reports and anonymous statistics only with your consent) and how to turn it off is described in the privacy policy.

Uninstalling

Wardly is removed like any Windows app: Settings → Apps → Wardly → Uninstall.
