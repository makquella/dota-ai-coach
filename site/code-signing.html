Політика підпису коду

Code signing policy · оновлено 11 жовтня 2026 року

Інсталятор Wardly для Windows поки без цифрового підпису. Тому Windows може показати «Windows захистив ваш комп'ютер»: натисніть «Докладніше» → «Однаково запустити». Сертифікат для підпису коду коштує грошей, а безкоштовні програми для відкритих проєктів беруть лише відомі проєкти — ми подамо заявку знову, коли Wardly стане помітнішим.

Як перевірити інсталятор

  • Інсталятор зібрано з відкритого коду цього репозиторію (ліцензія MIT) автоматично, у GitHub Actions (.github/workflows/release.yml), з коду релізного коміту. Скрипти збірки й налаштування CI — частина того самого відкритого коду.
  • Опис релізу зазвичай містить звіт VirusTotal. В адресі звіту — SHA-256 інсталятора: порівняйте її з хешем завантаженого файлу (PowerShell: Get-FileHash .\Wardly-Setup-0.55.0.exe). Якщо звіту немає, завантажте файл на virustotal.com самі.
  • Завантажуйте Wardly лише з цього сайту або зі сторінки релізів на GitHub.

Коли з'явиться підпис

  • Підписуватимуться лише інсталятор Wardly і програма в ньому, зібрані з цього репозиторію; сторонні бінарні файли — ніколи від імені проєкту.
  • Назва продукту в метаданих файлів — Wardly, версія однакова для всіх файлів одного релізу.
  • Кожен підпис потребуватиме ручного схвалення відповідальної особи.

Ролі

  • Автори й рецензенти (committers and reviewers): makquella. Зміни від інших людей (pull requests) потрапляють у код лише після перевірки.
  • Схвалення релізів (approvers): makquella — власник репозиторію.
  • Для доступу до репозиторію використовується двофакторна автентифікація.

Конфіденційність

Що Wardly зберігає на комп'ютері, що й коли надсилає (OpenDota, Valve CDN, GitHub, необов'язкові ШІ-сервіси, звіти й анонімна статистика лише за вашою згодою) і як це вимкнути — на сторінці Конфіденційність.

Видалення

Wardly видаляється як звичайна програма: «Параметри Windows → Програми → Wardly → Видалити».

Code signing policy

Updated 11 October 2026

The Wardly installer for Windows is not code-signed yet. Windows may therefore show “Windows protected your PC”: click “More info” → “Run anyway”. A code signing certificate costs money, and the free programs for open source projects accept only well-known ones — we will apply again once Wardly is better known.

How to check the installer

  • The installer is built automatically by GitHub Actions (.github/workflows/release.yml) from the open source code of this repository (MIT licence) at the release commit. Build scripts and CI configuration are part of the same open source code.
  • The release notes usually link a VirusTotal report. The report's address holds the installer's SHA-256: compare it with the hash of the file you downloaded (PowerShell: Get-FileHash .\Wardly-Setup-0.55.0.exe). If there is no report, upload the file to virustotal.com yourself.
  • Download Wardly only from this website or from the GitHub releases page.

Once it is signed

  • Only the Wardly installer and the app inside it, built from this repository, will be signed; third-party binaries never in the project's name.
  • The product name in the file metadata is Wardly, and the version is the same for every file of a release.
  • Every signing request will be approved manually.

Team roles

  • Committers and reviewers: makquella. Changes from anyone else (pull requests) are reviewed before they are merged.
  • Release approvers: makquella, the repository owner.
  • Multi-factor authentication is used for access to the repository.

Privacy policy

What Wardly keeps on your computer, what it sends and when (OpenDota, Valve CDN, GitHub, optional AI services, problem reports and anonymous statistics only with your consent) and how to turn it off is described in the privacy policy.

Uninstalling

Wardly is removed like any Windows app: Settings → Apps → Wardly → Uninstall.
