# Сайт Wardly

Статический лендинг без сборки: `index.html`, `styles.css`, `app.js` и `assets/`;
список героев с полными подсказками — отдельная страница `heroes.html` (меню «Герои»),
чтобы главная оставалась короткой
(шрифты, скриншоты приложения на двух языках, кадры игры и портреты героев, иконка, превью для соцсетей).
Всё грузится с того же домена — ни CDN, ни трекеров.

- Язык: русский по умолчанию, английский — по языку браузера или переключателю
  RU/EN (запоминается в `localStorage`). Русские тексты — в HTML, английские —
  в `app.js` (`EN`).
- Откуда пришёл посетитель: метка `?ref=<источник>` в ссылке (посты — см.
  `docs/marketing/`), иначе вид перехода (поиск, известный сайт, другой, прямой).
  Сайт один раз за визит отправляет только название источника
  (`POST api.luhovyimvp.dev/v1/hit`), кнопки «Скачать» идут через
  `api.luhovyimvp.dev/d/<источник>` — счётчик и сразу установщик последней версии.
  Итоги — на `api.luhovyimvp.dev/admin` («Откуда приходят»). Cookie нет.
- `robots.txt` и `sitemap.xml` — добавляйте в карту новые страницы.
- Номер версии и размер под кнопкой берутся из последнего релиза GitHub
  (`api.github.com/repos/makquella/dota-ai-coach/releases/latest`). Для посетителей
  репозиторий должен быть публичным.
- Карточка подсказки в первом экране показывает настоящие тексты советов
  приложения.
- `changelog.html` («Что нового») собирается из `docs/release-notes/` командой
  `python scripts/build_changelog.py` (шаблон — `scripts/changelog.template.html`).
  Руками не править: CI сверяет страницу с заметками.

## Посмотреть локально

```bash
cd site && python3 -m http.server 8080
# http://localhost:8080
```

## Адрес: luhovyimvp.dev

Сайт публикуется на GitHub Pages (Actions → *Website* → Run workflow,
`.github/workflows/pages.yml`) и открывается по адресу `https://luhovyimvp.dev`.
DNS домена — в Cloudflare, записи идут **через прокси Cloudflare** (оранжевое
облако): HTTPS выдаёт Cloudflare, GitHub отдаёт страницы.

- `A` для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`,
  `185.199.111.153`; `AAAA` для `@`: `2606:50c0:8000::153` … `2606:50c0:8003::153`;
  `CNAME` для `www` → `makquella.github.io`.
- В Cloudflare: SSL/TLS → режим **Full** (не Flexible и не Full strict),
  **Always Use HTTPS** включён. Галочка «Enforce HTTPS» в GitHub при прокси
  недоступна и не нужна.
- Записи почты (MX, TXT для Migadu) не трогать.
- Если сайт не открывается у игроков из России (в 2025 году провайдеры замедляли
  ресурсы за Cloudflare), переключите записи в «DNS only» (серое облако), а в
  GitHub → Settings → Pages включите Enforce HTTPS, когда выпустится сертификат
  (до часа; домен `.dev` без HTTPS не открывается).

Канонический адрес и превью ссылки (`og:image`) в `index.html` указывают на этот
домен. Другой хостинг: достаточно выложить содержимое `site/` в корень сайта.

## Обновить картинки

Все картинки сайта — настоящие: окна приложения (`assets/app/{ru,en}/`),
карточки оверлея (`assets/overlay/{ru,en}/`) и карточки разбора
(`assets/shots/{ru,en}/`) сняты с самого приложения на демо-данных; кадры игры
(`assets/game/`) — со страницы Dota 2 в Steam, портреты (`assets/heroes/`) — с
CDN Valve, те же, что показывает приложение. Переснять всё:
`scripts/site-shots/README.md`.

Шрифты: Montserrat (заголовки) и Inter (текст), оба OFL, лежат в `assets/fonts/`.
