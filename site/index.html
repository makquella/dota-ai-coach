Персональный тренер после матча

Ты играешь лучше, чем кажется. Разбор покажет, где теряешь.

Каждый твой матч записывается сам и дополняется данными OpenDota. Правила считают всё по цифрам, а ИИ-тренер объясняет матч простыми словами — каждое число в тексте сверено с данными.

  • Оценка матча: линия, фарм, выживание, драки, предметы
  • Карта на миникарте Доты: путь героя, места смертей и варды
  • Сборка и тайминги против статистики OpenDota
  • Ты против игрока твоего ранга в той же роли
  • Одна ошибка в фокусе — и счёт, получается ли её избегать
  • «Спросить тренера» — свой вопрос о матче
  • Сравнение с другом по его открытым матчам
  • Разбор можно отправить другу ссылкой — без Steam ID и ника

Частые вопросы

Могут ли забанить?

Нет. Game State Integration — официальная возможность Dota 2 от Valve. Приложение не внедряется в игру, не читает память и не управляет героем, а подсказки — такие же, как от друга в Discord.

Это правда бесплатно?

Да, полностью. Для ИИ-разбора нужен свой бесплатный ключ Google Gemini (получается за минуту); без него всё остальное работает так же.

Подсказки не видно поверх игры

Поверх эксклюзивного полноэкранного режима Windows не рисует окна. В Доте: Настройки → Видео → «Окно без рамки». Или включи голос — его слышно в любом режиме.

Для каких героев есть подсказки?

Полные подсказки (фарм, предметы, цели, способности) — для 64 героев: керри, мидеров, хардлайнеров и саппортов. На любом другом герое тренер подсказывает по выживанию (мало HP, серия смертей, контроль, мана, байбэк), даёт таймеры карты и подсказки роли. Разбор матча и прогресс работают для всех.

Откуда берётся история матчей?

Приложение само записывает каждый твой матч и дополняет его данными OpenDota. Для этого в Dota 2 должен быть включён общий доступ к данным матчей (Expose Public Match Data).

Нужен ли интернет?

Для подсказок во время игры — нет. Интернет нужен для истории с OpenDota, ИИ-разбора и обновлений.

Windows пишет «защитил ваш компьютер»

Установщик пока без цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае». Код открыт — можно проверить, что внутри.
