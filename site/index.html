Три шага

Поставил — и забыл, пока не начнётся матч

  1. 1

    Установи

    Приложение само найдёт Dota 2 в библиотеках Steam и положит маленький конфиг, через который игра делится данными матча. Останется добавить -gamestateintegration в параметры запуска Доты — приложение подскажет.

  2. 2

    Играй как обычно

    Подсказки появляются поверх игры, только когда Дота активна и идёт матч. Режим окна без рамки — или включи голос.

  3. 3

    Разбери игру

    Через пару минут после матча — оценка, главное на следующую игру и упражнения. Если реплей разобран OpenDota, разбор становится ещё точнее.

Твои данные — у тебя

История матчей, разборы и ключи лежат в локальной базе на компьютере. Приложение ходит только в OpenDota за публичной статистикой и, если включишь, к ИИ-сервису.

Правила решают, ИИ — формулирует

Что, когда и насколько срочно подсказать, решают проверяемые правила. Нейросеть — только по желанию и только после матча, с проверкой фактов.

Вопросы

Частые вопросы

Могут ли забанить?

Нет. Game State Integration — официальная возможность Dota 2 от Valve. Приложение не внедряется в игру, не читает память и не управляет героем, а подсказки — такие же, как от друга в Discord.

Это правда бесплатно?

Да, полностью. Для ИИ-разбора нужен свой бесплатный ключ Google Gemini (получается за минуту); без него всё остальное работает так же.

Подсказки не видно поверх игры

Поверх эксклюзивного полноэкранного режима Windows не рисует окна. В Доте: Настройки → Видео → «Окно без рамки». Или включи голос — его слышно в любом режиме.

Для каких героев есть подсказки?

Полные живые подсказки (фарм, предметы, цели, способности) — для 21 керри. На любом другом герое тренер подсказывает по выживанию: мало HP, серия смертей, контроль, мана, байбэк. Разбор матча, карта, сборка, драфт и прогресс работают для всех.

Откуда берётся история матчей?

Приложение само записывает каждый твой матч через GSI и дополняет его данными OpenDota. Для этого в Dota 2 должен быть включён общий доступ к данным матчей (Expose Public Match Data).

Нужен ли интернет?

Для подсказок во время игры — нет. Интернет нужен для истории с OpenDota, ИИ-разбора и обновлений.

Windows пишет «защитил ваш компьютер»

Установщик пока без цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае». Код открыт — можно проверить, что внутри.
